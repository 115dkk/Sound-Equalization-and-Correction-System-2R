# secs-rew

`secs-rew` provides real and fake Room EQ Wizard API transports.

This is an internal crate of SECS 2R. Its public items may change incompatibly in any release. The supported API is the [`sound-equalization-and-correction-system-rust-api`](https://crates.io/crates/sound-equalization-and-correction-system-rust-api) crate.

Repository: <https://github.com/115dkk/Sound-Equalization-and-Correction-System-2R>  
License: AGPL-3.0-only

SECS 2R은 한국 오디오 커뮤니티 스피커 갤러리에서 시작한 [SECS 2](https://github.com/Kim-O-O/Sound-Equalization-and-Correction-System-2)를 옮긴 프로그램이고, 보정 계산은 SECS 2의 방법을 그대로 따릅니다. SECS와 SECS 2를 만든 스피커 갤러리 여러분과 업스트림 저작자께 감사드립니다.
