# SECS 2 재라이선스 허가 (AGPLv3)

SECS 2R의 공개 크레이트와 PyPI 패키지를 AGPL-3.0-only로 다시 라이선스한 근거입니다(ADR 0023). SECS 2는 GPL-3.0-only로 공개된 소스이므로, 그 코드를 담은 패키지를 AGPLv3로 바꾸려면 저작자의 허가가 필요했습니다. 이 허가가 없었다면 재라이선스는 할 수 없었습니다. 허가해 주신 김ㅇㅇ님께 감사드립니다.

## 허가한 사람과 때

- 허가한 사람: SECS 2의 저작자 KIM-O-O(디시인사이드 스피커 갤러리 닉네임 김ㅇㅇ)
- 받은 사람: SECS 2R 유지보수자(115dkk)
- 시각: 2026-10-30 19:54:42(한국 시간, 글에 표시된 시각)
- 방법: 유지보수자의 문의에 단 답글

## 허가 글

스크린샷([`2026-10-30-secs2-agpl-permission.jpg`](2026-10-30-secs2-agpl-permission.jpg))의 글을 그대로 옮깁니다.

> 안녕하세요, 정성스러운 문의 감사합니다
>
> SECS 2는 처음부터 스갤러분들이 자유롭게 쓰고 발전시키라고 공개한 소스입니다. 그러니 API로 만들어 Crates.io / PyPI 에 올리시는 것은 물론 환영이고, 해당 API 패키지에 포함된 SECS 2를 AGPLv3로 재라이선싱하시는 것도 허락합니다.
>
> 말씀하신 대로 AGPL로 가는 게 저도 좋은 방향이라고 생각합니다. 좋은 작업 응원합니다. 감사합니다.

## 허가의 범위

- crates.io와 PyPI에 올리는 API 패키지에 포함된 SECS 2 코드를 AGPLv3로 다시 라이선스하는 것입니다. SECS 2R에서는 crates.io에 올리는 크레이트 16개와 PyPI 패키지 `secs2r`가 여기에 해당합니다(ADR 0023).
- SECS 2R 앱과 게시하지 않는 크레이트는 GPL-3.0-only 그대로입니다.
