# 0036. MIMO 위치별 가드

상태: 채택, 2026-11-04

## 배경

유지보수자가 공유한 두 번째 P1 분석(`SECS2R_vs_Dirac_ART_심층분석.md`, 2026-10-31)은 MIMO의 T60 가드가 모든 위치의 대역 에너지를 더한 뒤 비교하므로, 한 자리가 나빠져도 합이 좋아지면 통과한다고 지적했습니다. 코드로 확인했습니다. `mimo/design.rs`의 `BandGuard::energies`는 대역마다 모든 위치의 늦은 에너지를 `total`에 더하고, `T60Guard::evaluate_mode`는 모드마다 위치들의 기준 에너지와 시험 에너지를 각각 더한 뒤 비교합니다. IIR 실현의 `iir::BandGuard::power`도 위치를 더하고, `OutcomeGuard`는 같은 `T60Guard`를 씁니다. 서포트를 줄일지는 이 두 가드가 정합니다. 대역의 늦은 에너지가 1 dB 넘게 늘거나 모드의 꼬리가 0.15 넘게 길어지면 서포트를 3 dB씩 줄이고, 다섯 번 뒤에는 끕니다.

MIMO 설계는 측정한 모든 위치(3곳 이상)를 씁니다. 설계에 쓰지 않는 위치는 없으므로 그런 위치를 따로 검사할 일은 없습니다.

## 결정

보정 설정에 **MIMO 위치별 가드**(`mimo_seat_guard`, 기본 꺼짐)를 추가합니다. 끄면 MIMO 계산은 지금과 비트 단위로 같습니다. MIMO만의 설정이므로 `mimo_key`에 들어가고, 바꿔도 보정 결과는 낡지 않고 MIMO 결과만 낡습니다.

### 규칙

켜면 두 가드가 위치의 합 대신 **가장 나빠지는 위치**를 봅니다.

- **대역 가드.** 대역마다 위치마다 `10·log10(시험 뒤 늦은 에너지 / 기준 늦은 에너지)`를 구하고, 위치 가운데 가장 큰 값을 그 대역의 값으로 삼습니다. 한도 1 dB는 그대로입니다. 1/3 옥타브 대역과 늦은 봉우리 ±1.5 Hz 대역을 보는 것도 그대로입니다.
- **T60 가드.** 모드마다 위치마다 꼬리 에너지의 비율을 구하고, 가장 큰 값을 모드의 값으로 삼습니다. 한도 0.15와 '가장 센 모드의 20 dB 안'의 모드 선택은 그대로입니다.
- **IIR 실현.** `iir::BandGuard`와 `OutcomeGuard`도 같은 규칙입니다. 위치마다의 에너지를 더하지 않고 따로 두었다가 가장 큰 비율을 씁니다.
- **가중.** 기준 위치에 가중을 두지 않습니다. 가드는 어느 자리도 나빠지지 않게 하는 장치이므로 자리마다 같은 무게입니다.
- **줄이는 순서.** 서포트를 3 dB씩 줄이고 다섯 번 뒤 끄는 절차는 그대로이고, 판정만 바뀝니다.

### 메모

`GuardReduced`와 `GuardDisabled` 메모의 원인(`GuardCause`)에 판정이 나온 위치를 가드마다 추가합니다(`band_position`, `tail_position`). 두 가드가 다른 자리에서 한도를 넘을 수 있기 때문입니다. 켜져 있을 때만 값이 있고, 꺼져 있으면 지금처럼 없습니다. 화면은 '위치 3에서 100~125 Hz 늦은 에너지 +1.4 dB'처럼 원인마다 자리를 보입니다. 기준 에너지가 0인 위치에 서포트가 에너지를 만들면 위반으로 치고, 전후 모두 0인 위치만 건너뜁니다.

### 화면과 저장

- 보정 설정의 MIMO 카드에 'MIMO 위치별 가드'를 둡니다. 설명은 서포트를 줄일지 정할 때 모든 위치의 합 대신 가장 나빠지는 위치를 본다는 것, 한 자리가 나빠지는 설계를 막는 대신 서포트가 더 자주 줄어든다는 것입니다. 위치가 셋 미만이면 MIMO처럼 쓸 수 없습니다.
- 프로젝트 파일에는 켰을 때만 `mimo_seat_guard: true`를 저장하고, 업스트림 SECS 2는 이 키를 무시합니다(D58). `mimo_key`에는 켰을 때만 `|seat_guard`를 덧붙입니다.
- CLI는 `project set --mimo-seat-guard on|off`로 바꿉니다.

### 확인

- 합성 방에서 위치 하나만 나빠지는 서포트는 끄면 통과하고 켜면 줄어드는 것, 끈 계산이 MIMO 골든과 비트 단위로 같은 것, 메모의 위치를 시험으로 확인합니다.

## 결과

- 켜면 어느 자리도 MIMO 때문에 나빠지지 않습니다. 대신 서포트가 더 자주 줄거나 꺼지므로 늦은 에너지의 평균 개선은 작아질 수 있습니다.
- 기본값은 업스트림의 합산 판정 그대로입니다. 어느 쪽이 들리는 결과에서 나은지는 ART 게이트 자료와 사용자 제보로 봅니다.
