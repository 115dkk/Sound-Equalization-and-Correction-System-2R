# 0038. '고급'에 둔 설정의 승격과 노출 조건

상태: 채택, 2026-11-04

## 배경

이슈 #131의 세 번째 항목은 '고급'에 묻힌 기능 가운데 중요하고 자주 쓰는 것을 적절한 설계와 함께 메인 화면으로 올리는 일입니다. 유지보수자는 여기서 적절한 설계란 disclosure를 포함한다고 적었습니다. 쓸모없는 상황에서는 보이지 않는 것도 설계의 일부입니다.

지금 '고급' 아래에는 다음이 있습니다.

| 화면 | '고급' 안의 설정 |
|---|---|
| 보정 범위 카드 | 부스트 상한, 해석적 미분(실험, ADR 0012) |
| 크로스오버 카드 | 크로스오버 PEQ 수와 하한·상한 |
| 서브 정렬 카드 | 인프라 서브(XO, 필터 종류, 부스트 상한), 설정할 서브우퍼와 그 편집기, 메인 추가 딜레이 |
| MIMO 카드 | 하한 자동·하한, 입력당 최대 서포트, 초기 구간(실험, ADR 0037), 서포트를 FIR로 계산 |
| 측정 옵션 카드 | 스윕 길이, 스윕 반복 |
| 시스템 타이밍 | 기준 스피커, 기준 출력 |
| 시스템 DSP | 채널당 FIR 탭, 총 FIR 탭 예산, 채널당 IIR 밴드, 채널당 올패스 밴드, 베이스 매니지먼트 경로 딜레이 |
| 내보내기 | 보정 전후 mdat |

유지보수자는 2026-11-04에 이 가운데 **부스트 상한**, **스윕 길이·반복**, **서브우퍼별 설정·메인 추가 딜레이**를 올리기로 골랐고, 채널당 FIR 탭·IIR 밴드는 '고급'에 두기로 했습니다. 앞서 ADR 0025, 0030, 0031은 ART에 가까워지려는 계열의 설정을 '고급'에 두지 않기로 했고, ADR 0012와 0037은 실험 설정을 '고급'에 두었습니다.

## 결정

### '고급'에 남는 것의 기준

'고급'은 다음 세 가지만 담습니다. 이 기준에 들지 않는 설정은 카드 본문에 두되, 뜻이 없는 상황에서는 표시하지 않습니다(노출 조건).

- 실험 설정. 결과를 아직 실측으로 확인하지 못한 것입니다(해석적 미분, MIMO 초기 구간).
- 자원 예산. 장치 프로필이 정하고 사용자가 바꿀 일이 드문 수(FIR 탭, IIR 밴드, 올패스 밴드, 경로 딜레이, 크로스오버 PEQ 수, 입력당 최대 서포트).
- 드문 구성. 특정한 기기 구성에서만 뜻이 있는 것(기준 스피커·출력, 인프라 서브, MIMO 하한과 FIR 실현, 보정 전후 mdat).

### 올리는 셋과 노출 조건

1. **부스트 상한**은 보정 범위 카드의 본문으로 갑니다. 자리는 '딥 보정 제한' 토글 바로 위입니다. 둘 다 보정이 얼마나 손댈지 제한하는 설정이기 때문입니다. RC 메모 줄은 상한이 어떻게 정해졌는지 말하므로 지금처럼 상한 입력 바로 아래에 남고, 부스트 상한은 그 뒤의 추가 구간·극저역 보호 다음에 옵니다. 항상 보입니다. 보정 범위의 '고급'에는 해석적 미분만 남고(1개), 켜져 있으면 지금처럼 펼쳐진 채로 시작합니다.
2. **스윕 길이**와 **스윕 반복**은 측정 옵션 카드의 본문, '시작 지연' 아래로 갑니다. 스윕 길이는 항상 보이고, 반복은 지금처럼 REW에서 음향 기준이 아닐 때만 보입니다. 측정 옵션의 '고급'은 비므로 없앱니다.
3. **설정할 서브우퍼**와 그 편집기, **메인 추가 딜레이**는 서브 정렬 카드의 본문, 서브별 방식 선택과 계산 단추·경고 아래로 갑니다. 카드 자체가 서브가 둘 이상일 때만 표시되므로 그 조건을 그대로 씁니다. 편집기는 자동 방식 서브에도 고정 필터와 MIMO 서포트 항목이 있으므로 카드가 보이면 함께 보이고, 값(게인·딜레이·극성·올패스)은 지금처럼 고정 방식이거나 상대값 고정 묶음일 때만 보입니다. 메인 추가 딜레이는 지금처럼 고정 방식 서브가 있을 때만 보입니다. 서브 정렬의 '고급'에는 인프라 서브 묶음만 남습니다.

안정 id(`calibrate.range.boost`, `measure.options.sweep`, `measure.options.repeats`, `calibrate.ba.edit`, `calibrate.ba.editor`, `calibrate.ba.main_delay`)는 그대로입니다. `measure.options.advanced`는 사라집니다. 투어 장면과 갤러리 견본은 '고급'을 펴지 않고 그 항목에 닿도록 고칩니다. 튜토리얼의 인프라 서브 퀘스트는 서브 정렬의 '고급' 안을 가리키므로, 튜토리얼 프로젝트에서는 그 카드의 '고급'을 펼친 채 시작합니다(`baAdvanced`). 처음 고를 서브를 정하는 `editSub`는 더 이상 '고급'을 열지 않습니다.

### 확인

- 보정 화면 시험에서 '고급'을 펴지 않고 부스트 상한을 바꿀 수 있고, 보정 범위의 '고급'이 1개를 세며, 서브 정렬에서 '고급'을 펴지 않고 서브를 골라 편집기가 보이고, 고정 방식 서브가 있을 때만 메인 추가 딜레이가 보이며, '고급'을 펴면 인프라 서브만 있는 것을 확인합니다.
- 측정 화면 시험에서 '고급' 없이 스윕 길이를 바꿀 수 있고 반복은 음향 기준이 아닐 때만 보이는 것을 확인합니다.
- 투어 장면과 갤러리 견본이 고친 자리에 표시되는 것을 확인합니다.

## 결과

계산과 내보낸 파일은 바뀌지 않으므로 편차 항목은 없습니다. 이 ADR은 '고급'의 기준을 정하므로, 다음 감사는 이 기준에 맞는 설정을 '고급'에서 꺼내자고 다시 제안하지 않습니다. 새 설정을 추가할 때는 위 세 기준에 드는지 보고 자리를 정합니다.
