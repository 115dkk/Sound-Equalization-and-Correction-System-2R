# 0028. 보정할 때 XO 추천 포함

상태: 채택, 2026-10-31

## 배경

업스트림 SECS 2처럼 SECS 2R도 크로스오버 추천을 'XO 추천 계산' 버튼으로 따로 계산합니다. 추천은 후보(60, 80, 100, 120 Hz)마다 BA와 RC를 포함한 설계를 통째로 계산해 점수를 매기므로, 보정 설정이 바뀌면 추천도 바뀝니다. room 사례에서는 1점 안팎의 거의 동점 후보끼리 순위가 바뀌었습니다(2026-10-31 확인). 0.41.0 사용자는 계산할 때마다 추천이 바뀐다며 추천 버튼을 매번 따로 눌러야 하는지 물었습니다. 유지보수자는 보정 앞에 'XO 추천 포함' 선택을 두고 기본을 켜짐으로 하기로 했습니다. 꺼서 얻는 것은 계산 시간뿐이고, 그 시간이 중요한 사용자는 직접 끌 수 있기 때문입니다.

## 결정

- 보정 설정에 `xo_rec_include`(기본 켜짐)를 추가합니다. 엔진 키에는 들어가지 않습니다(설계는 적용된 XO로 정해짐). 프로젝트 파일에는 껐을 때만 `xo_rec_include: false`를 저장하고, 업스트림 SECS 2는 이 키를 무시합니다.
- 켜져 있고 서브가 있으면 '보정 계산'과 '다시 보정하기'는 먼저 XO 추천을 계산합니다. 추천이 XO에 적용되면, 이미 있는 흐름대로 이어서 보정을 계산합니다(MIMO 선택도 지금처럼 따름). 서브가 없으면 이 선택은 보이지 않고 보정만 계산합니다.
- 사용자가 그룹의 XO를 직접 바꾸면 `xo_rec_include`를 끕니다. 켜 둔 채로 두면 다음 보정이 직접 넣은 값을 추천값으로 덮어쓰기 때문입니다. 화면은 그 사실을 알립니다.
- 'XO 추천 계산' 버튼은 그대로 두어, 보정 없이 추천만 다시 볼 수 있게 합니다.
- 추천을 계산한 입력이 그 뒤에 바뀌면 화면이 추천을 지난 값으로 표시합니다(추천 키, 0027과 같은 PR).

## 결과

- 기본 설정으로 보정하면 XO가 매번 그때의 설정에 맞는 추천값으로 정해집니다. 업스트림은 사용자가 추천을 누를 때만 바꾸므로, 같은 프로젝트를 업스트림과 SECS 2R에서 보정하면 XO가 다를 수 있습니다(D51).
- 보정 시간은 서브가 있는 프로젝트에서 대략 후보 수만큼 늘어납니다. 끄면 지금과 같습니다.
