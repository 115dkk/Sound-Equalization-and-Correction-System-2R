# 0005. REW 없이도 측정한다: 자체 측정을 들이고 REW 연동은 남긴다

상태: 채택, 2026-10-13

## 배경

업스트림은 측정을 전부 REW(Room EQ Wizard)에 맡깁니다. 스윕 재생과 녹음, 레벨 체크의 신호 발생, 입력 레벨 미터가 모두 REW API를 거칩니다. 자동 측정은 REW Pro의 API 기능이라 Pro가 없으면 REW에서 따로 잰 `.mdat`를 가져와야 하고, 그 경로에서는 장치 확인, 레벨 체크, 측정을 차례로 건너뛰어야 합니다. REW는 훌륭한 도구지만, 사실상 유료 라이선스를 전제로 하는 데다 함께 들고 다니기에는 너무 큰 외부 프로그램입니다.

임펄사이퍼 3.x는 스윕 측정을 직접 합니다. Windows는 WASAPI만(wasapi-rs의 안전한 API, exclusive 우선, 거부되면 shared와 자동 변환), macOS와 Linux는 cpal을 쓰고, 손으로 쓰는 unsafe 없이 이것을 해냈습니다.

## 결정

- **자체 측정을 들입니다.** `secs-audio`가 스윕 설계, 재생·녹음 세션, 디컨볼루션, 타이밍 레퍼런스, 레벨 체크, 마이크 보정 파일을 맡습니다. 장치는 `AudioBackend` seam으로 들어옵니다. WASAPI 어댑터와 cpal 어댑터는 `secs-sys`에 두고 앱이 주입합니다(0002). 시작 예산은 손으로 쓰는 unsafe 0입니다.
- **임펄사이퍼의 관례를 따릅니다.**
  - Windows는 WASAPI만 씁니다. ASIO, DirectSound, MME는 쓰지 않습니다.
  - 기본은 exclusive를 먼저 시도하고 거부되면 shared와 자동 변환으로 엽니다. 사용자가 모드를 고정하면 폴백 없이 열고, 거부되면 그대로 알립니다.
  - 측정 세션은 입력을 먼저 열고 준비를 확인한 뒤 출력을 끝까지 재생하고 비우고, 입력을 멈추고 두 스레드를 합칩니다. 세션 객체는 스레드 사이를 오가지 않습니다.
  - wasapi-rs는 0.25 이상을 씁니다. 그 판부터 `WaveFormat::parse`와 `Device::from_raw`가 `unsafe fn`이라 `forbid(unsafe_code)`가 컴파일 단계에서 막습니다.
- **REW 연동은 남깁니다.** 업스트림의 모든 기능을 들고 가므로 REW API 측정(`secs-rew`의 RealRew)과 mdat 가져오기는 그대로 지원합니다. 측정 방식은 서비스의 측정 seam 뒤에서 셋 중 하나를 고르는 일이 됩니다. 셋은 자체 측정, REW, 그리고 테스트와 튜토리얼용 모의 측정입니다.
- **모의 측정은 실제 경로를 탑니다.** 튜토리얼과 테스트는 업스트림 샘플 IR(돌비 룸 7.1.4)로 스윕을 컨볼루션해 녹음처럼 돌려주는 모의 백엔드를 씁니다. 그래서 디컨볼루션부터 보정 계산까지 실제 코드가 돕니다.
- **새 기능 표시.** 자체 측정은 업스트림에 없는 기능이므로 `features.toml`에 `measure.native`로 따로 등록하고, 화면에서는 REW Pro 없이 측정하는 기본 경로로 둡니다.

## 결과

- REW Pro 없이도 측정부터 내보내기까지 SECS 2R 하나로 끝낼 수 있습니다.
- 운영체제 오디오는 `secs-sys`에만 있고 나머지 크레이트는 장치 없이 테스트됩니다.
- 실제 장치에서의 동작은 CI 러너로 확인할 수 없는 부분이 있습니다. 임펄사이퍼처럼 하드웨어 프로브 예제와 실측 기록(`docs/HARDWARE.md`)을 M4에서 함께 남깁니다.
