# 0024. 보정 범위 추가 구간

상태: 채택, 2026-10-31

## 배경

유지보수자는 보정 범위를 두 곳 이상 지정하는 기능을 요청했습니다(#131, 2026-10-31). 예로 든 것은 20~300 Hz와 15000~20000 Hz이고, 20 Hz 미만이나 20000 Hz 초과는 거부합니다.

지금 보정 범위는 `rc_lo`부터 `rc_hi`까지 한 구간입니다. 상한은 ADR 0021의 기준(엄격한 슈뢰더, 너그러운 슈뢰더, 측정 위치 일치도, 직접 입력)으로 정합니다. 엔진에서 이 구간을 쓰는 곳은 아래와 같습니다(`crates/secs-engine/src/rc.rs`).

- **보정 목표 마스크.** dB 보정에 양쪽 램프를 곱합니다. 아래쪽은 `rc_lo/√2`에서 0, `rc_lo`에서 1이고, 위쪽은 `rc_hi`에서 1, `rc_hi·√2`에서 0입니다. 램프는 log2 주파수에 선형이라, 경계마다 구간 밖으로 반 옥타브에 걸쳐 줄어듭니다.
- **부스트 금지 마스크.** `max(rc_lo, 20)`부터 `rc_hi`까지의 격자에서 계산합니다.
- **PEQ 맞춤.** Zero 모드는 두 번 맞춥니다. 낮은 쪽은 `max(15, rc_lo/1.4)`~400 Hz이고, 높은 쪽은 400 Hz~`min(rc_hi, 20000)`입니다. FIR 모드의 PEQ는 20~500 Hz에서 맞추고 대역 중심을 `rc_hi` 아래로 제한합니다. 맞춤은 구간 밖의 잔차를 시드에서 0으로, 다듬기에서 가중치 0.15로 둡니다(`fit.rs`).
- **2단계 FIR 다듬기.** `max(rc_lo, 20)`~`rc_hi`의 불리언 마스크를 씁니다.
- **FIR 실현.** FIR은 마스크를 거친 목표 크기를 전 대역에 걸쳐 만들고, 초과 위상만 `rc_hi·√2`에서 줄입니다. `max(20, lo_fir)`~`rc_hi·√2` 대역은 위상 보정 강도를 고를 때 FIR의 크기 오차를 재는 범위입니다(`Realizer`).
- **위상과 GD.** 초과 위상 보정은 `rc_hi`~`rc_hi·√2`에서 줄어들고, 위상 후보 점수와 GD 컷은 구간 안에서 계산합니다.
- **긴 모드 피크.** `rc_lo`~`min(rc_hi, 160)` 안의 피크만 남깁니다.

MIMO, 레벨 맞춤(300~3000 Hz), 극저역 보호(ADR 0022), 베이스 매니지먼트는 이 구간을 읽지 않습니다. 16 kHz 위 부스트를 2 dB로 묶는 상한도 구간과 상관없이 늘 걸립니다.

지금은 `rc_lo < rc_hi`인지 어디서도 확인하지 않습니다. 하한은 10~200 Hz, 상한은 100~20000 Hz로 따로 자를 뿐이라 하한 200, 상한 100도 저장됩니다. 업스트림 SECS 2도 같습니다.

## 결정

### 설정

- 지금의 `rc_lo`, `rc_hi`, `rc_hi_basis`, `rc_hi_transition`은 **기본 구간**으로 그대로 둡니다. 상한의 한계(100~20000 Hz)와 자동 상한도 그대로입니다.
- 기본 구간의 하한도 20 Hz 미만을 거부합니다(유지보수자 결정, 2026-10-31). 화면, CLI, 편집 IPC는 20~200 Hz만 받습니다. 업스트림이 허용하는 10~19 Hz로 이미 저장된 파일은 읽을 때 바꾸지 않으므로 계산은 지금과 같고, 그 값을 다시 고칠 때만 20 Hz 이상을 요구합니다(D48).
- 보정 설정에 **추가 구간** `rc_bands`(기본 비어 있음)를 둡니다. 구간마다 하한과 상한을 직접 입력합니다. 자동 상한은 기본 구간에만 있습니다.
- 추가 구간은 `20 ≤ 하한 < 상한 ≤ 20000`(Hz)이어야 하고, 최대 4개입니다. 어기는 편집은 값을 자르지 않고 거부합니다. 서비스는 이유(`rc_band_range`: 몇 번째 구간과 그 값, `rc_band_count`)를 담은 `invalid_input`으로 답합니다. 서비스는 받은 구간을 하한 순으로 정렬해 저장합니다.
- 기본 구간의 상한을 직접 입력할 때 하한 이하이면 거부합니다. 하한을 바꿔 직접 입력한 상한 이상이 되어도 거부합니다. 이미 그렇게 저장된 파일은 읽을 때 바꾸지 않습니다.
- 구간끼리 겹치거나 맞닿으면 합집합으로 봅니다. 기본 구간의 상한은 자동이면 계산해야 알 수 있으므로, 편집할 때 겹침을 이유로 거부하지 않습니다.

### 엔진

엔진은 기본 구간(상한을 정한 뒤)과 추가 구간을 정렬하고, 겹치거나 맞닿는 구간을 합쳐 **보정 구간 집합**을 만듭니다.

- **보정 목표 마스크**는 구간마다 지금과 같은 반 옥타브 램프를 만들고 그 최댓값을 씁니다. 구간 사이는 램프가 닿지 않는 곳에서 보정하지 않습니다.
- **부스트 금지 마스크**와 **2단계 FIR 다듬기 마스크**는 구간 집합 전체에서 계산합니다.
- **Zero 모드의 PEQ 맞춤**은 구간 집합을 가중치로 씁니다. 집합 밖의 잔차는 지금처럼 시드에서 0, 다듬기에서 0.15이고, 높은 쪽 맞춤은 400 Hz부터 구간 집합의 가장 높은 상한까지 맞춥니다.
- **FIR 모드**에서는 추가 구간을 FIR이 맡습니다. 목표 마스크가 추가 구간을 열면 FIR이 그 크기를 만들고, 위상 보정 강도를 고를 때 크기 오차를 재는 범위를 구간 집합(위쪽 끝은 구간마다 상한×√2, 나이퀴스트 아래)으로 넓혀 추가 구간의 오차도 함께 봅니다. 20~500 Hz에서 맞추는 FIR 모드의 PEQ 단계는 바꾸지 않습니다.
- **위상과 GD**도 추가 구간에서 보정합니다(유지보수자 결정, 2026-10-31).
  - 초과 위상의 페이드는 구간마다 만들고 그 최댓값을 씁니다. 기본 구간은 지금처럼 15 Hz 아래 램프와 상한에서 상한×√2까지의 페이드를 쓰고, 추가 구간은 하한/√2에서 하한까지 올라가고 상한에서 상한×√2까지 내려갑니다. 위상 기준(3~6 kHz의 GD 중앙값)은 바꾸지 않습니다.
  - 위상 후보 점수와 GD 컷은 구간 집합에서 계산합니다.
  - 고역 위상은 측정 위치에 따라 크게 달라지고, 그 위상을 보정하면 앞울림이 생기기 쉽습니다. 지금도 위상 보정 강도는 FIR의 크기 오차가 기준(RMS 0.5 dB, 최대 2 dB 또는 강도 0일 때보다 각각 0.3 dB, 1 dB 이내)을 넘지 않는 가장 큰 단계로 고릅니다. 이 오차를 구간 집합 전체에서 재므로, 추가 구간에서 오차가 커지면 위상 보정 강도가 내려갑니다.
- **긴 모드 피크**는 지금처럼 160 Hz 아래에서 고르되, 구간 집합 안의 피크만 남깁니다.
- **자동 상한**은 기본 구간에만 있으므로, 측정 위치 일치도 기준의 탐색 계산(`rc_hi = 2000`)은 추가 구간 없이 돌립니다. 추가 구간이 일치도 상한을 바꾸지 않습니다.
- 추가 구간이 없으면 위의 범위와 마스크는 모두 지금과 같습니다.
- 16 kHz 위 부스트 2 dB 상한, 극저역 보호, MIMO, 레벨 맞춤, 베이스 매니지먼트는 바꾸지 않습니다. 15~20 kHz 같은 추가 구간에서도 부스트는 2 dB까지입니다.
- 추가 구간이 없으면 결과는 지금과 비트 단위로 같습니다. 골든과 오라클 시험이 이를 지킵니다.

### 저장과 호환

- 프로젝트 파일의 보정 설정에는 추가 구간이 있을 때만 `rc_bands: [[하한, 상한], ...]`를 저장합니다. `CALIBRATION_SHAPE`에 선택 키로 둬서, 병합할 때 지운 목록이 되살아나지 않게 합니다.
- 업스트림 SECS 2는 모르는 키를 무시하므로 이 파일을 열면 기본 구간만 보정합니다(D48). 읽을 때 규칙을 어기는 구간은 버리고, 남은 구간이 4개를 넘으면 앞의 4개만 씁니다.
- `engine_key`에는 추가 구간이 있을 때만 덧붙이므로 옛 결과의 키는 그대로입니다.

### 서비스와 IPC

- 편집 `SettingEdit::RcBands { bands }`가 추가 구간 목록 전체를 한 번에 바꿉니다. 빈 목록이면 추가 구간을 모두 지웁니다.
- 계산 메모에 `rc_bands`를 남깁니다. 합친 뒤의 보정 구간 집합을 하한과 상한의 문자열 목록으로 담습니다. 기본 구간만 있으면 남기지 않습니다.
- 결과 그래프 응답에 `rc_bands_hz`(보정 구간 집합)를 추가합니다. 화면에서는 그 합집합 바깥이 음영으로 보입니다. 지금의 `rc_band_hz`는 기본 구간으로 남깁니다.
- 내보내기 텍스트와 CamillaDSP 메모에는 추가 구간을 한 줄로 덧붙입니다.

### CLI

`secs2r-cli project set --rc-bands 15000-20000[,하한-상한...]`으로 추가 구간을 바꾸고, `--rc-bands none`으로 지웁니다.

### 화면

보정 설정의 범위 카드에서 기본 구간의 하한과 상한 아래에 '보정 구간 추가'를 둡니다. 추가 구간이 없으면 이 단추 하나만 보입니다. 구간을 추가하면 구간마다 하한과 상한 입력, 삭제 단추가 나타나고, 거부된 값은 그 입력 옆에 이유를 보여 줍니다. 4개를 채우면 추가 단추를 숨깁니다.

## 결과

- 추가 구간을 두지 않으면 계산, 파일, 화면이 지금과 같습니다.
- 추가 구간도 위상까지 보정합니다. 고역 위상 보정이 앞울림을 만들면 위상 보정 강도 사다리가 강도를 낮추지만, 크기 오차로 드러나지 않는 앞울림까지 막지는 못합니다.
- 추가 구간이 있으면 Zero 모드의 높은 쪽 PEQ 맞춤 범위가 넓어져 쓰는 PEQ 필터가 늘 수 있습니다. 필터 수의 상한은 지금과 같습니다.
- 업스트림 SECS 2로 연 파일은 기본 구간만 보정합니다.
- 기본 구간의 하한을 편집할 때 업스트림은 10 Hz까지 받지만 SECS 2R은 20 Hz부터 받습니다(D48).
