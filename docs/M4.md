# M4 이식 지도: 측정, 서비스, 잡, CLI

M4는 SECS 2R이 화면 없이도 한 바퀴를 도는 단계입니다. 측정하거나 가져오고, 설계하고, MIMO를 계산하고, 내보냅니다. [`ARCHITECTURE.md`](ARCHITECTURE.md) 8절의 M4 행을 여기서 작업 단위로 나눕니다.

## 1. 업스트림에서 알게 된 것

- **업스트림은 오디오 입출력을 하지 않습니다.** 스윕 재생, 녹음, 디컨볼루션, 레벨 체크 신호와 미터를 모두 REW HTTP API(`127.0.0.1:4735`)로 시킵니다. 그래서 자체 측정([ADR 0005](adr/0005-native-measurement.md))에는 옮길 업스트림 코드가 없습니다. 대신 임펄사이퍼 3.x(MIT)의 오디오 크레이트를 출처를 적고 가져옵니다.
- **측정의 정본은 `.secs`와 `.irs`입니다.** 역할마다 `<프로젝트>.irs/<역할>_P<위치>.wav`(모노 float32)와 위치별 기록 `{pos, label, uuid, mdat, ir, spl_db, t0, spl_offset, done, sample_rate, source}`을 남기고, IR 하나를 잴 때마다 프로젝트를 저장합니다. 저장할 때 곁에 `<이름>.mdat`도 씁니다.
- **긴 작업은 스레드와 프로세스 풀입니다.** 측정은 `QThread`, 계산은 데몬 스레드, XO 추천과 MIMO는 spawn 프로세스 풀(코어 절반, 낮은 우선순위)입니다. 취소는 결과만 버립니다(D17).
- **계산 캐시는 피클입니다.** `.irs/calibration_cache.pkl`을 제한 없이 역직렬화합니다(S1).
- **무결성 점검은 `--check` 하나입니다.** 모듈 23개를 불러오고 프로세스 풀을 한 번 돌려 JSON을 찍습니다.

## 3. 경계와 seam

- **측정 방식 seam(`secs-service`).** 셋 중 하나를 고릅니다.
  - 자체 측정: `secs-audio`와 앱이 주입한 `AudioBackend`.
  - REW: `secs-rew`의 `RewClient`.
  - 모의: 시뮬레이션 방 백엔드를 끼운 자체 측정. 업스트림 샘플 IR(돌비 룸 7.1.4)로 스윕을 컨볼루션해 녹음처럼 돌려주므로 디컨볼루션부터 실제 코드가 돕니다(ADR 0005).
  - 세 방식 모두 결과는 같은 모양의 측정 기록 하나입니다: 역할, 위치, IR, 레이트, t0, SPL, SNR, 출처.
- **`AudioBackend`(`secs-audio`).** 임펄사이퍼의 트레이트(열거, 프로브, 출력·입력 세션)와 세션 규약(입력을 먼저 열고 준비를 확인한 뒤 출력을 끝까지 재생하고 비움, 세션 객체는 스레드를 오가지 않음)을 그대로 씁니다. 어댑터는 WASAPI·cpal(`secs-sys`, 앱이 주입)과 시뮬레이션 방(테스트·모의)입니다.
- **REW 전송(`secs-rew` 안쪽).** HTTP(`ureq`, TLS 없이)와, 업스트림 테스트의 실제 REW 응답을 담은 기록 대화입니다. 콜백 서버는 표준 라이브러리 위의 작은 HTTP 서버로, 무작위 경로 토큰을 쓰고 본문을 끝까지 읽습니다(R3).
- **`Host`(`secs-service`).** 대화상자, 폴더 열기, 알림을 앱이 주입합니다. 테스트는 기록 호스트를 씁니다.
- **잡.** 종류(측정, 설계, 서브, XO 추천, MIMO, 내보내기)마다 하나만 동시에 돕니다. 취소 토큰이 엔진 안쪽 반복까지 내려가고, 결과는 버리지 않고 낡음으로 표시합니다(D17). 진행은 잡 이벤트(`JobEvent`)로 흐릅니다.
- **IPC.** 메서드마다 `secs-types::ipc`에 요청과 응답 변형을 두고 `features.toml`에 `ipc.<메서드>`로 등록합니다. 잡 이벤트는 별도 채널입니다.

## 4. 이번 단계의 편차

| 번호 | 작업서 | 내용 |
|---|---|---|
| F1 | P20 | `.secs` 저장을 임시 파일과 이름 바꾸기로, 쓰는 쪽은 서비스 하나 |
| F2 | P20 | 채널마다 바로 기록하고, 위치를 다시 재면 그 위치를 바꿈 |
| F5 | P20 | IR 경로를 `.irs` 안으로 제한, 벗어나면 이주 경고 |
| R1–R4 | P22 | Pro 판정, 측정 세션의 차단기, 콜백 경로와 본문, FakeREW의 테스트 코드 의존 |
| S1 | P23 | 버전 붙은 실행 캐시. 옛 피클은 읽지 않고 다시 계산 |
| D17 | P23 | 협조적 취소, 종류마다 잡 하나, 낡음 표시 |
| U1, U5 | P23 | 레벨 체크 결과로 스윕 레벨을 정하는 메서드, 측정을 지우는 동작의 확인과 되돌리기(화면은 M5) |

## 5. 판정

- **업스트림과 같아야 하는 함수**(계획, 서명, 시간 추정, 역할 짐작, mdat 배정)는 오라클 가족 `service_plan`, `service_mdat`로 맞춥니다.
- **REW 대화**는 업스트림 `tests/test_rewapi_real.py`의 기록 응답과 요청 순서·본문까지 같아야 합니다.
- **자체 측정**은 시뮬레이션 방에서 알려진 IR을 스윕으로 재고 디컨볼루션해 되찾는 왕복으로 확인합니다(오차 한계는 P21에서 정함). 임펄사이퍼에서 가져온 부분은 임펄사이퍼의 테스트도 함께 옮깁니다.
- **흐름 전체**: 모의 측정 → 설계 → MIMO → 내보내기를 서비스와 CLI로 돌리는 테스트가 CI에서 돕니다.
- **무결성 잡**: 같은 입력을 `RAYON_NUM_THREADS=1`과 기본 스레드로 돌려 내보낸 파일의 해시가 같아야 합니다(ADR 0007). CI 설계는 Claude가 합니다.
- **하드웨어 실측**: 프로브 예제를 실제 장치에서 돌린 기록을 `docs/HARDWARE.md`에 남깁니다. CI 러너에는 오디오 장치가 없으므로 유지보수자의 기계에서 한 번 돕니다.

## 6. 순서

```text
P20 계획·기록·저장(secs-project) ─┬─ P23 서비스: 잡, 캐시, 측정 seam, mdat, 내보내기, IPC ─ P25 CLI, 무결성 잡
P21 자체 측정 핵심(secs-audio) ───┼─ P24 운영체제 오디오(secs-sys), 프로브, HARDWARE.md
P22 REW(secs-rew) ────────────────┘
```

P20, P21, P22는 크레이트가 겹치지 않아 나란히 돕니다. P23은 셋의 타입을 쓰므로 그 뒤에, P24는 P21의 트레이트 뒤에 돕니다. 화면 연결은 M5입니다.

## 7. 끝나는 조건

- CLI만으로 샘플 프로젝트를 설계하고 내보냅니다.
- 모의 측정으로 측정부터 내보내기까지 흐름 전체가 CI에서 통과합니다.
- 무결성 잡이 CI에서 통과합니다.
- 하드웨어 프로브를 실제 장치에서 돌린 기록이 있습니다.
- 이 단계의 업스트림 테스트(측정·세션, REW, mdat 가져오기, 잡·캐시, 내보내기 묶음, CLI)가 확인하는 동작을 Rust 테스트가 모두 확인합니다.

## 8. 서비스 인터페이스

### 잡과 이벤트

- 오래 걸리는 요청(측정, 레벨 체크, mdat 가져오기, 보정 계산, XO 추천, MIMO, 내보내기)은 잡을 시작하고 곧바로 `job_started { job, kind }`를 돌려줍니다. 진행과 결과는 그 요청과 함께 넘긴 이벤트 싱크로 갑니다(ADR 0003: 앱은 Tauri `Channel`, CLI는 표준 출력, 테스트는 수집기).
- 이벤트는 `Started`, `Progress { stage, done, total }`, `Log { code, params }`, `Finished { status, result, error }` 넷입니다. 문장이 아니라 코드와 값을 보내고, 화면이 언어에 맞게 씁니다.
- 잡은 무리마다 하나만 돕니다(D17).
  - 장치 무리: 레벨 체크, 측정, mdat 가져오기. 프로젝트의 측정을 바꿉니다.
  - 계산 무리: 보정 계산, XO 추천, MIMO.
  - 내보내기 무리: 내보내기.
  - 같은 무리의 잡이 돌고 있으면 `job_busy`로 거절합니다. 취소는 협조적이고, 결과는 버리지 않고 낡음으로 표시합니다.
- 측정이 바뀌면 보정 결과가, 보정 결과가 바뀌면 MIMO 결과가 낡음으로 바뀝니다. 낡음은 업스트림의 서명(`measurement_signature`, `target_key`, `engine_key`, `mimo_key`)으로 판정합니다.

### 주입

앱이 `Service::new(Deps)`에 넘깁니다.

- 오디오 백엔드를 만드는 함수(`secs-sys`).
- REW 전송과 프로세스 조회(`secs-sys`).
- 메모리 조회(`secs-sys`).
- 호스트(대화상자, 폴더 열기, 알림, M5).

CLI와 테스트는 가상 방과 기록 전송을 넘깁니다.
