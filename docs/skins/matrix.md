# Signal Matrix (`matrix`) 디자인 헌법

> **공항 출발 안내판 / 방송국 라우팅 매트릭스.** 모든 것이 격자에 정렬되고, 모든 행은 좌표를 가진 셀이며, 색은 상태에만 허락됩니다.

EqualizerAPO-XT의 [`docs/skins/matrix.md`](https://github.com/115dkk/EqualizerAPO-XT/blob/main/docs/skins/matrix.md)를 SECS 2R의 재료로 옮긴 헌법입니다. Qt의 `MatrixMetrics`와 페인터 조문은 CSS 토큰과 선택자의 조문이 되었습니다.

## 철학

Signal Matrix는 '화면은 보드(board)다'라는 단일한 은유로 움직입니다. 사용자는 메뉴를 살펴보는 것이 아니라 계기판을 조작합니다. 단계를 고르는 것은 버스를 선택하는 것이고, 항목을 고르는 것은 크로스포인트를 체결(engage)하는 것입니다.

색은 상태에만 배급되어 보드는 단색이고, 세 스킨 중 색이 정보 채널로서 가장 엄격하게 보존되어 램프 하나가 켜지는 순간이 가장 크게 읽힙니다. 치수는 전부 모눈 위에 앉습니다. 정렬은 미덕이 아니라 규칙입니다.

## 불변 규칙

1. **색 배급제.** 신호등 색(녹/노랑/적)은 상태 전용으로 예약하고 장식에 쓰지 않습니다. 액센트 시안(색상 215)은 체결·선택·호버 예고와 라우팅된 신호 데이터(타겟 점, XO 선, 고른 위치) 전용입니다. 보드·라벨·배지는 단색으로 그립니다. 비활성(결항)은 색이 아니라 형태(점선 룰, 속 빈 램프, 취소선, 저알파)로 말합니다.
2. **라운드 0 + 1px 룰.** 직각 셀과 1px 괘선만 씁니다. 곡률·그림자·글로우를 금지합니다. 모든 반지름 토큰을 0으로, 그림자 토큰을 1px 룰(`0 0 0 1px var(--border)`)로 덮습니다. 이 스킨의 모서리 언어는 직사각형입니다.
3. **모든 것은 격자 위에.** `--skin-grid-pitch: 24px`(12px 두 줄)가 보드의 모눈이고, 줄 높이·칩 높이·간격은 이 피치의 배수나 절반입니다. 카드 사이와 머리 주변의 보드 표면(`.app-content`의 바탕)에 깔린 흐린 세로 모눈선(다크 알파 0.08, 라이트 0.06)은 장식이 아니라 보드의 정체성이므로 지우지 않습니다. 단, 모눈은 보드 표면까지입니다. 카드 본문은 불투명 패널이 모눈을 덮습니다.
4. **행 = 좌표를 가진 셀.** 단계 레일의 단계, 표의 줄, 목록의 항목은 왼쪽 3px 상태 레일과 좌표 셀(모노 굵은 약호: 단계 `S1`…`S5`, 측정 위치 `P01`, 채널은 역할 코드)을 가집니다. 좌표 잉크는 평시 muted, 체결(선택) 시에만 액센트입니다. 좌표는 필터링이나 정렬에 따라 재부여하지 않습니다.
5. **수치는 모노 + 박스 셀.** 권위 있는 판독값은 언제나 박스 안의 모노 숫자입니다(값 칸, 표의 숫자 칸, 미터 판독, 상태 요약의 값, 그래프 커서 값). 함몰 바탕(`--surface-sunken`) + 1px 룰 + 굵은 모노 잉크의 라운드 0 셀이 표준형입니다.
6. **크로스포인트 호버.** 표와 목록의 호버는 행 밴드와 열 밴드를 동시에 켜고(`:has()`로 열을 찾을 수 있을 때), 둘의 교차부가 가장 밝습니다. 단추와 칩의 호버는 셀 프리라이트(1px 액센트 룰 + 옅은 액센트 채움)입니다. 점이 아니라 교차로 읽혀야 합니다.
7. **크리스프 1px.** 괘선과 모눈은 정수 픽셀에 앉힙니다. 반 픽셀의 흐린 선은 이 스킨에서 버그입니다. 곡선 데이터(그래프 트레이스)에만 안티에일리어싱을 허용합니다.
8. **텍스트 화살은 ASCII만.** 방향·캐럿은 kit의 `Icon`이 그리고, 텍스트 화살은 `>`만 허용합니다. 스캔 캐럿(`> _`)은 보드의 입력 표기입니다.

## 색 의미론

신호등과 액센트의 의미는 보드 전체에서 단 하나입니다. 아래 표가 법이고, 구현이 표와 다르면 구현이 틀린 것입니다.

| 색 | 의미 | 구현 위치 |
|---|---|---|
| 녹(success) | 가동/완료/저장됨 | 단계 레일의 실선 램프(완료), 상태 알약(완료·적정·연결됨), 미터의 적정 띠 |
| 노랑(warning) | 확인 필요/바이패스/주의 | 속 빈 램프(막힘), 낡은 결과의 점선 룰, 레벨 높음 |
| 적(danger) | 실패/위험/파괴적 동작 | 잡 실패, 클리핑, 지우기 단추의 프리라이트 |
| 청(info) | 진행 중 | 진행 막대의 세그먼트, 진행 알약 |
| 액센트 시안 | 체결·선택·호버 예고, 라우팅된 신호 데이터 | 체결 셀의 LED 채움, 선택 룰, 크로스포인트 밴드, 지금 단계의 3px 체결 밴드, 타겟 점·XO 선, 고른 측정 위치 |

이 다섯 줄 밖의 색 사용은 전부 장식이며 금지입니다. 기본 토큰 값(다크 / 라이트): 액센트 `--accent-hue` 215, `--accent-chroma` 0.13, L 0.80 / 0.58(`#22D3EE` / `#008EAA` 근방, 라이트는 대비 게이트에 맞춰 한 단 어둡게); `--info`는 액센트와 떨어진 청색 260; success 150, warning 88, danger 27은 기본 값에서 채도를 유지합니다. 보드의 중립색은 차가운 무채(색상 250, 채도 0.004 이하)이고, `--bg`는 다크 `oklch(0.17 0.004 250)` / 라이트 `oklch(0.975 0.003 250)`, `--surface`는 다크 `oklch(0.21 0.004 250)` / 라이트 `oklch(0.995 0.002 250)`입니다.

## 빛과 상태의 문법

- **hover:** 크로스포인트 예고입니다(불변 규칙 6).
- **selected/engaged:** 셀이 체결됩니다. 액센트 LED 채움(저알파) + 1px 액센트 룰이고, 지금 단계는 3px 체결 밴드를 받습니다.
- **focused:** 정사각 셀 브래킷입니다(`outline: 1px solid var(--accent); outline-offset: 1px` + 안쪽 1px 룰). 글로우가 아닙니다.
- **disabled:** 결항 처리된 출발편입니다. 점선 외곽 룰 + 속이 빈 노란 램프 + (제목에) 취소선으로 말하고, 행은 보드에 남습니다. 안내판에서 결항 편이 사라지지 않기 때문입니다.
- **dragging:** 점등 색이 한 단 밝아집니다.

## 타이포그래피

라벨은 UI 글꼴(Pretendard), 수치·코드·좌표는 `--font-mono`입니다. 위계는 격자 위치와 균일한 활자가 만들고, 크기 변화로 위계를 만들지 않습니다(보드의 모든 행은 같은 활자를 씁니다). 제목 토큰(`--text-title`)만 남기고 카드 제목은 UI 크기의 대문자 자간 캡션(`--text-ui`, 자간 0.06em)입니다.

## 차별화 게이트의 답

| # | 항목 | Matrix의 답 |
|---|---|---|
| 1 | 단계 레일 | 버스 목록. 각 단계는 좌표 셀(`S1`…`S5` 모노) + 왼쪽 3px 상태 레일(완료 녹 실선, 지금 액센트 체결 밴드, 막힘 노랑 속 빈 램프 + 점선 룰, 건너뜀 취소선). 제목은 단색 |
| 2 | 주 동작 | 체결 셀: 액센트 채움, 라운드 0, 1px 액센트 룰, 모노 대문자 라벨 아님(라벨은 UI 글꼴, 단색 `--on-accent`). 누름은 한 단 밝은 체결 |
| 3 | 카드 chrome | 직각 셀, 1px 룰, 머리 밴드(`--surface-sunken`)와 본문 사이 1px 룰, 그림자 없음. 보드 표면에만 모눈 |
| 4 | 상태 표기 | 알약은 정사각 램프 셀(실선 = 가동, 속 빈 = 주의, 점선 = 결항) + 모노 약호 없이 명사구. 진행 막대는 세그먼트 바(피치 절반 간격). 낡음은 점선 외곽 룰 |
| 5 | hover와 focus | 크로스포인트 프리라이트 / 정사각 브래킷 |
| 6 | 비활성 | 결항: 점선 룰 + 속 빈 램프 + 취소선, 보드에 남음 |
| 7 | 숫자 판독 | 함몰 박스 모노 셀(값 칸·표 숫자·미터 판독·상태 요약 값·그래프 커서) |
| 8 | 그래프 바탕 | 함몰 데이터 셀: `--surface-sunken` 바탕, 크리스프 1px 모눈(마이너 저알파, 메이저 한 단), 0 dB 버스는 본문 잉크 1px, 축 숫자는 모노 태그 셀, 우상단 커서 판독 셀 |

## 구성 요소별 표현

### 앱 틀: 버스 레일과 마스트헤드

레일은 버스 목록이고(게이트 1), 로고 타일은 보드의 모서리에 앉되 그림은 그대로입니다. 단계 머리는 마스트헤드입니다. 제목은 단색 UI 활자, 상태 알약은 램프 셀, 주 동작은 체결 셀, 막힌 이유는 `!` 마커의 모노 리마크 한 줄입니다. 작업 트레이는 보드 발치의 리마크 라인(1px 룰 위의 함몰 스트립, `>` 마커, 진행 세그먼트)입니다. 프로젝트 상태 요약은 좌표 셀 + 값 셀의 2열입니다.

### 단추와 칩

주 동작은 체결 셀입니다. 보조 단추는 캡션 키(1px 보더 룰 + 옅은 채움, 공유 조문 5의 이 보드 형태), 조용한 단추는 투명 기능 셀(호버 프리라이트, 누름 체결), 위험 단추는 danger 룰 + danger 프리라이트입니다. 분할 단추는 셀 열차이고 고른 조각은 체결 셀입니다. 범례 칩은 점선 알약이 아니라 직각 셀이며, 끈 칩은 결항(점선 + 취소선)입니다.

### 입력칸, 선택기, 토글

값 칸은 함몰 모노 셀(불변 규칙 5)이고 네이티브 스핀 버튼은 이 보드에 없습니다(스테퍼의 ± 는 캡션 키). 선택기는 1px 룰의 드롭다운 존과 캐럿을 유지합니다(선택기임이 보여야 합니다). 토글은 두 칸짜리 체결 셀(켜짐 칸이 액센트 LED)입니다. 입력 중은 액센트 체결, 비활성은 점선 취소입니다.

### 표와 목록

표는 보드의 본진입니다. 머리줄은 단색 모노 약호 또는 UI 캡션, 줄은 1px 룰, 숫자 칸은 모노, 고른 줄은 체결된 버스(액센트 저알파 채움 + 왼쪽 3px 밴드, 레일의 지금 단계와 같은 문법)이고 줄을 액자처럼 두르지 않습니다(둘러싼 줄은 키로 읽힙니다). 호버는 크로스포인트입니다. 묶음 머리줄은 보드 섹션 표제(함몰 밴드)입니다.

### 미터

레벨 미터는 세그먼트 미터 셀입니다. 함몰 셀에 피치 절반 간격의 세그먼트, 적정 띠는 녹색 세그먼트, 클리핑은 적색 세그먼트 점등, 판독값은 옆의 모노 셀입니다.

### 그래프와 배치도

그래프는 게이트 8의 함몰 데이터 셀입니다. 채널 곡선 색은 데이터이므로 그대로이고, 타겟 점은 정사각 크로스포인트 셀(휴지 속 빈 룰, 호버 프리라이트 + 플롯을 관통하는 1px 행·열 헤어라인, 선택 체결)입니다. XO 선은 액센트 1px 스캔 룰입니다. 배치도는 보드의 좌표 평면이고, 표식은 정사각 셀(공유 SVG가 둥근 사각형으로 그리고 이 스킨이 `rx: 0`으로 모서리를 없앰), 고른 위치는 체결, 완료는 녹색 실선 룰입니다.

### 팝오버, 메뉴, 대화상자, 토스트, 툴팁

팝오버와 메뉴는 보드 위의 셀 묶음(1px 룰, 그림자 없음)이고 고른 항목은 체결 셀입니다. 대화상자는 두꺼운 2px 룰의 보드 패널입니다. 토스트는 보드 발치의 리마크(면 + 1px 룰 + 왼쪽 킬, 본문은 모노 판독 라인, 닫기 셀은 danger 프리라이트)입니다. 킬의 색은 배급표를 따릅니다. 중립 토스트는 보더 잉크, 완료·주의·실패는 그 상태색이고, 액센트는 체결이 아니므로 쓰지 않습니다(판례: P65 감사). 툴팁은 모노 리마크 셀입니다.

### 튜토리얼 레이어

코치 카드는 보드 패널이고 강조 링은 정사각 브래킷(액센트 1px + 모서리 틱)입니다. 튜토리얼 강조색(자홍)은 배급표에 없는 색이라 이 보드에 들어오지 못합니다(`[data-skin="matrix"][data-accent]`가 시안을 유지).

## 하지 말 것

- 신호등 색·액센트를 장식이나 타입 식별에 쓰지 않습니다. 색 배급제가 1조입니다.
- 곡률, 그림자, 글로우, 그라데이션 장식을 쓰지 않습니다. 모서리 언어는 직사각형입니다.
- 모눈 질감을 지우거나 비-배수 치수를 들이지 않습니다.
- 좌표·번호를 필터링/정렬에 따라 재부여하지 않습니다. 좌표는 불변입니다.
- 비활성 행을 숨기거나 흐리게 뭉개지 않습니다. 결항 편은 보드에 점선으로 남습니다.
- 권위 있는 수치를 UI 글꼴로 쓰지 않습니다. 박스 모노 셀입니다.
- 누름에 스케일 변화를 쓰지 않습니다. 셀은 체결됩니다.

## 이웃 스킨과의 경계

가장 가까운 이웃은 **Instrument**(둘 다 차가운 중립색, 선으로 만든 구조)입니다. Instrument는 둥근 면과 그림자, UI 글꼴의 숫자이고, Matrix는 직각 셀, 모눈, 좌표, 모노 숫자입니다. Matrix가 좌표와 램프를 잃으면 Instrument로 퇴화합니다. 점등 어휘는 **Rack**과도 닿지만, Rack의 LED는 베젤에 박힌 물리 부품이고 Matrix의 LED는 보드 셀의 추상 점등입니다(스큐어모피즘 금지).

## 새 요소를 이 스킨답게 만드는 법

1. 이 요소를 보드의 셀/레일/램프/판독 스트립 중 무엇으로 만들 것인가?
2. 치수가 24px 피치의 배수나 절반에 앉는가?
3. 색을 쓰려는 곳이 상태인가? 아니라면 단색으로 되돌린다.
4. 항목에 좌표/약호를 줄 수 있는가? 줬다면 불변인가?
5. 호버가 교차(행 밴드 × 열 밴드)로 읽히는가?
6. 1px 선을 정수 픽셀에 앉혔는가?
7. 권위 있는 수치가 박스 모노 셀에 있는가?
