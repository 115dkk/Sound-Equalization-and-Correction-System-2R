# Instrument (기본 스킨) 디자인 헌법

> **차분하고 정밀한 계측기.** 그래프와 숫자를 읽는 애호가와 설치 기사의 화면. 데이터가 있는 곳만 촘촘하고 나머지는 여백과 중립색으로 조용합니다.

기본 스킨은 `data-skin` 속성이 없는 상태이고, 값의 정본은 [`DESIGN.md`](../DESIGN.md)입니다. 이 문서는 그 값이 지키는 철학과, 다른 두 스킨과의 경계, 그리고 2026-10-22의 색 감사 기록을 적습니다.

## 철학

화면은 계측기입니다. 구조는 선으로, 깊이는 투명한 그림자 고리로, 위계는 글자 크기와 여백으로 만듭니다. 색은 뜻을 가진 곳(주 동작, 고른 것, 상태)에만 있고, 그 밖의 모든 색은 한 기운의 중립색에서 명도와 투명도로 파생합니다. 둥근 모서리(4·6·10·14)는 겹친 면이 바깥 = 안쪽 + 간격을 지키는 동심원이고, 움직임은 짧고 끊을 수 있습니다.

이 스킨의 공식 타이브레이커는 한 질문입니다. **"이 장식이 없으면 읽기가 어려워지는가?"** 아니라면 빼는 쪽이 이 스킨입니다.

## 불변 규칙

1. **강조색 하나.** 강조색은 '누를 수 있음'과 '지금 고른 것'입니다. 정적인 글자에는 쓰지 않고, 화면마다 채운 단추는 주 동작 하나입니다.
2. **중립색은 한 기운.** 바탕·면·글자·경계는 모두 강조색의 색상(255–258)에 아주 낮은 채도를 얹은 차가운 회색입니다. 따뜻한 회색이 섞이면 이 스킨이 아닙니다.
3. **깊이는 그림자, 구조는 선.** 카드와 보조 단추는 투명 그림자 고리, 표의 줄·레일 경계·입력칸 테두리는 선입니다. 어두운 테마의 그림자는 흰 1px 고리 하나입니다.
4. **동심 반지름.** 24px보다 가깝게 겹친 면은 바깥 반지름 = 안쪽 + 간격입니다.
5. **상태는 점 + 명사구.** 상태 알약은 채운 점과 명사구 하나이고, 색만으로 뜻을 전하지 않습니다.
6. **바뀌는 숫자는 `tabular-nums`.** 글꼴은 UI 글꼴 그대로이고 모노 글꼴은 코드와 원문 오류에만 씁니다.
7. **움직임은 상태 전환에만.** 100·150·220ms, ease-out, 누르면 0.96배. 장식용 움직임이 없습니다.

## 차별화 게이트의 답

| # | 항목 | Instrument의 답 |
|---|---|---|
| 1 | 단계 레일 | 번호가 든 원형 표식과 제목. 완료는 success 점의 확인 표시, 지금은 강조색 왼쪽 띠, 막힘은 자물쇠와 캡션 한 줄 |
| 2 | 주 동작 | 강조색으로 채운 6px 단추, 글자는 `--on-accent` 세미볼드 |
| 3 | 카드 chrome | 10px 모서리, 투명 그림자 고리, 제목·도움말·동작의 머리줄 |
| 4 | 상태 표기 | 알약(색 점 + 명사구), 진행 막대, 낡음은 카드 왼쪽의 경고색 띠 |
| 5 | hover와 focus | hover는 같은 색상의 한 단계 밝거나 어두운 면, focus는 강조색 2px 외곽선 2px 띄움 |
| 6 | 비활성 | 흐린 글자(`--text-faint`)와 눌림 바탕, 커서 기본 |
| 7 | 숫자 판독 | UI 글꼴의 `tabular-nums`, 단위는 캡션 크기로 옆에 |
| 8 | 그래프 바탕 | 면 색 바탕, 9% 알파의 모눈, 캡션 크기의 축 글자, 로그 주파수 눈금 고정 |

## 하지 말 것

- 강조색을 정적인 글자나 장식에 쓰지 않습니다.
- 따뜻한 회색을 들이지 않습니다. 중립색의 색상은 255–258입니다.
- 채운 색 배지로 종류를 구분하지 않습니다. 종류는 글자가 말합니다.
- 그림자를 구조에, 선을 깊이에 쓰지 않습니다.
- 모노 글꼴을 숫자 칸에 쓰지 않습니다(그것은 Matrix의 어휘입니다). 숫자는 `tabular-nums`로 맞춥니다.
- 질감(브러싱, 모눈)을 바탕에 깔지 않습니다.

## 이웃 스킨과의 경계

Rack은 깊이를 부품의 물리(베벨, 나사, 우물)로 만들고, Instrument는 투명한 그림자의 추상으로 만듭니다. Matrix는 라운드 0과 1px 괘선, 모노 숫자 셀이고, Instrument는 둥근 모서리와 UI 글꼴의 `tabular-nums`입니다. Instrument에서 베벨이나 모눈 질감이 보이면 이웃을 침범한 것입니다.

## 새 요소를 이 스킨답게 만드는 법

1. 이 요소에 색이 필요한가? 상태나 주 동작이 아니면 중립색이다.
2. 깊이가 필요한가? 그림자 고리 토큰 셋(`--shadow-card`, `--shadow-control`, `--shadow-raised`) 중 하나다.
3. 겹친 면의 반지름이 동심인가?
4. 바뀌는 숫자에 `tabular-nums`를 걸었는가?
5. 상태를 점 + 명사구로 말하는가?
6. hover가 같은 색상의 한 단계인가, 새 색이 아닌가?
