# 측정 리샘플링 검증

P60은 48 kHz가 아닌 측정을 계산 전에 변환하는 선택 기능입니다.
기본값은 기존처럼 계산 중단이며, 48 kHz 입력은 변환하지 않습니다.
설정은 프로젝트에 저장하고 계산 결과의 낡음과 캐시에 반영합니다.

## 원작의 처리

조사 대상은 `UPSTREAM.toml`에 고정한 Beta 1.3.1,
`587159ed8a6077f146ccd7de023de80203462739`입니다.

- `src/secs/correction_engine.py:491~498`: 기준 위치의 IR이 48 kHz가 아니면
  오류를 냅니다. 실제 Python `_prepare()` 호출에서도 44.1/96 kHz가 거부됩니다.
- 같은 파일 506~513과 `long_spectra()` 546~560: 다른 위치의 샘플레이트를
  변환하지 않고 48 kHz로 취급합니다. 다른 위치의 44.1 kHz 입력이 수용되는
  것도 실제 호출로 확인했습니다.
- mdat 가져오기와 REW 저장은 원래 샘플레이트와 `t0`를 보존합니다.
- 원작 `CalibrationSettings.from_project()`는 2R 전용 정책을 무시합니다.
  프로젝트 자체의 읽기·저장은 키를 보존할 수 있지만, 보정 설정 변경이나
  XO 추천 반영 시 `store()`가 보정 설정 전체를 다시 써 이 키가 사라집니다.
  그 파일을 2R에서 다시 열면 계산 중단 기본값을 사용합니다.

## 변환 정의

독립적으로 작성한 windowed-sinc/polyphase 변환입니다.
수학적 참고는 SciPy의 [upfirdn](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.upfirdn.html),
[resample_poly](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.resample_poly.html),
[대칭 Blackman-Harris 창](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.windows.blackmanharris.html)입니다.
표준 창 함수와 polyphase 식을 현재 DSP 크레이트에 구현하고 참고 주소를
파일 머리에 기록했습니다. 추가 런타임 의존성은 없습니다.

입출력 레이트를 최대공약수로 약분한 비율을 `U/D`로 두고, FIR 반길이는
`96 × max(U,D)`, 차단 주파수는 두 Nyquist 주파수 중 낮은 값의 0.96배입니다.
창은 계수 `0.35875, 0.48829, 0.14128, 0.01168`의 대칭 4항
Blackman-Harris입니다.

일반 파형과 달리 IR은 전달함수 크기를 보존해야 하므로 커널 합을 `U`가 아닌
`D`로 맞춥니다. 입력 IR의 합으로 나누는 방식은 쓰지 않으며, DC가 0인
응답과 전부 0인 응답도 처리합니다.

양끝의 필터 응답을 모두 보존합니다. 커널 앞에 넣는 0의 수를 `p`,
반길이를 `L`이라 할 때:

```text
p = (D - L % D) % D
선행 출력 샘플 수 = (L + p) / D
출력 길이 = floor(((입력 길이 - 1) × U + 2L + p) / D) + 1
계산용 t0 = 원본 t0 - 선행 출력 샘플 수 / 48000
```

이 시간 원점 보상으로 필터 지연이 측정 도착 시각에 더해지지 않습니다.
원본 샘플과 원본 `t0`는 그대로 두며, 변환본만 `Samples::F64`로 보관합니다.

## 검증 범위

| 검사 | 판정 기준 |
|---|---|
| 독립 SciPy 1.18.1 전체 배열 | 출력 길이·선행 샘플 수 일치, 최대 절대 오차 `< 2e-12` |
| 첫·마지막·분수 격자 임펄스 | DC 오차 `< 1e-6`, 0~20 kHz 복소 응답 오차 `< 1e-5` |
| 96→48 kHz 앨리어싱 | 30/36/45 kHz 시험 신호의 alias 크기 비율 `< 1e-5` |
| 44.1→48 kHz 이미지 | 21 kHz 시험 신호가 만드는 23.1 kHz 이미지 비율 `< 1e-5` |
| 일반 레이트와 지원 경계 | 8/11.025/32/44.1/88.2/96/192/384 kHz의 대역 내 응답·양끝 |
| 기존 입력 보존 | Reject와 이미 48 kHz인 입력의 Arc·샘플·`t0` 비트 유지 |
| 혼합 레이트 | 여러 위치의 동일한 물리적 도착 시각과 원본 보존 |
| 잘못된 입력·자원 | 범위 밖 레이트, 빈/비유한 데이터, 길이 넘침, 예산 초과 |
| 취소 | 커널 생성·스케일·출력 반복과 엔진 진입에서 취소 확인 |
| 서비스 실제 경로 | 96 kHz 기본 거부, 변환 후 보정·XO·캐시 mdat 내보내기 |
| 파일·설정 | 원본 WAV 바이트와 측정 메타 보존, 정책 왕복, 보정/MIMO 낡음 |

독립 배열과 생성기는 `crates/secs-dsp/tests/data/resample_ir_scipy.json`,
`generate_resample_ir.py`입니다. 기능 등록부의 `engine.measurement_resampling`이
주요 수치·통합 검사를 가리킵니다.

조정자가 같은 로컬 프로브를 다시 실행한 결과입니다. 1초 합성 IR을 5회 변환한
중앙값이며, 전체 보정 계산 시간과는 별도입니다.

| 입력 → 출력 | 변환 중앙값 | 10 ms부터 취소 조건을 반환한 시험의 종료 시각 |
|---|---:|---:|
| 44.1 → 48 kHz | 5.74 ms | 10.13 ms |
| 96 → 48 kHz | 8.61 ms | 10.08 ms |

## 자원과 확인한 한계

- 지원 레이트는 8,000~384,000 Hz입니다. 비율 자체의 인위적인 상한은 두지
  않으며, 47,999/383,999 Hz처럼 큰 커널이 필요한 경우도 할당 전에 예산을 확인합니다.
- 변환 단계는 새 출력 전체, 가장 큰 Vec→Arc 이전 사본, 가장 큰 커널을
  합산해 예약합니다. 반환 후 보관되는 샘플은 기존 엔진의 입력 메모리 규칙을
  따릅니다. 변환 permit을 다음 계산까지 유지해 서로 기다리는 구조는 피했습니다.
- 커널 생성·스케일·출력은 256개 단위, 입력 유효성 검사는 4096개 단위로
  취소를 확인합니다. 커널 `pairwise_sum` 앞뒤에도 확인합니다. 최대 크기 커널의
  단일 합산 구간에 대한 최악 취소 지연은 별도로 실측하지 않았습니다.
- 캐시 내보내기는 계산 당시 변환 정책을 복원합니다. 원본 측정이 나중에
  바뀌었을 때 과거 파형까지 되살리는 기능은 추가하지 않았습니다.
