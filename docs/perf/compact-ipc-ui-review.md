# 화면 결과와 작업 기록 UI 검토

모드: **full**. 기준: make-interfaces-feel-better.
범위: 보정·내보내기 결과 소비, 세션 완료 처리, 작업 트레이와 모의 서비스.
React 19와 기존 CSS 토큰을 유지했습니다. 새 화면·스타일·문구는 추가하지 않았습니다.

## 범위와 확인 근거

| 항목 | 확인 근거 | 결과 |
|---|---|---|
| Typography | `Settings.tsx`, `ExportScreen.tsx`, 보정·내보내기 전후 8쌍 | 역할·개수·탭 수 표시 유지, 앱 영역 픽셀 동일 |
| Surfaces | 같은 8쌍과 화면 컴포넌트 diff | 레이아웃·버튼·테두리 변경 없음 |
| Icons | 화면 컴포넌트 diff와 캡처 | 아이콘 변경 없음 |
| Color | CSS·카탈로그 diff, 캡처 | 색과 상태 의미 변경 없음 |
| Animations | 변경 파일과 상태 전환 코드 | 새 모션 없음. 기존 애니메이션의 10% 재생 검토는 이번 범위 밖 |
| Performance | DTO 직렬화 감사, 100–150회 완료 테스트, 세션·트레이 보관 코드 | 계수 전송 제거, 완료 32개 및 활성 작업 보존 |
| Writing | 기존 문구·카탈로그와 결과 필드 소비 | 문구·번역 변경 없음 |
| Interruptions | 활성 작업·취소·완료 처리 테스트 | 새 방해 화면 없음, 작업 추적과 취소 상태 유지 |

정적 비교 상태는 `calibrate.mimo-settings`, `calibrate.gpu-auto`,
`export.ready`, `export.rc-only`의 ko/en입니다. 영어 PNG 4쌍은 파일도 동일합니다.
한국어 차이는 앱 밖 갤러리 제목(y < 27px)에만 있으며, **앱 영역은 8쌍 모두
픽셀 동일**합니다. 조정자가 두 결과 화면을 직접 보고 8쌍의 RGB 픽셀 비교를
별도로 재실행했습니다. [해시·픽셀 비교 기록](compact-ipc-ui-comparison.json)을 참조합니다.

## 해결한 사항

| 심각도 | 위치 | Before | After | 이유 |
|---|---|---|---|---|
| MEDIUM | 보정 `Settings.tsx`, 내보내기 `types.ts`·`ExportScreen.tsx`, `ipc/fixtures.ts`·`mock.ts` | 역할·개수 표시에도 DSP 원본을 전달하고 배열을 순회 | `main_roles`, `sub_roles`, `input_count`, `fir_taps_total` 소비 | 화면에 필요 없는 전송·파싱·보관 제거 |
| MEDIUM | `state/session.ts`, `app/jobs/jobStore.ts` | 완료 작업과 요청 문맥이 누적되고 세션 작업에 전체 결과 보관 | 결과 없는 완료 메타데이터 32개, 모든 활성 작업, 수명이 끝난 문맥 제거 | 반복 작업의 보관량 제한 |
| HIGH | `state/jobTracker.ts`, `state/jobRetention.ts`, `app/jobs/useJobs.ts` | 빠른 완료의 재처리, 늦은 응답으로 상태 복원, 프로젝트가 바뀐 뒤의 완료 처리 경합 | 요청 소유권·프로젝트 세대·완료 관찰 순서·스냅샷 조회 범위로 처리 | 중복 조회와 잘못된 결과·활성 상태 표시 방지 |

작업 ID 배정과 서로 다른 채널의 시작 알림 순서는 같다고 가정하지 않습니다.
처음 도착한 시작 알림과 자체 요청의 승인 응답은 작은 ID라는 이유로 버리지 않고,
오래된 스냅샷의 재등장 방어는 별도로 적용합니다.

## 검토 후 제외한 변경

| 후보 | 제외 이유 |
|---|---|
| 프로젝트 교체 때 작업 기록 전체 삭제 | 아직 실행 중인 작업의 추적을 끊습니다. 전역 기록 상한과 프로젝트 세대 검사로 필요한 수명을 보존합니다. |
| 별도 완료 로딩 화면 추가 | 이번 변경은 전송 데이터와 보관 수명의 수정입니다. 기존 완료 흐름을 유지하며 실제 화면 정지 시간을 새로 가정하지 않습니다. |

## 검증과 판정

타입 검사, **47개 파일·423개 UI 테스트**, 앱 빌드와 갤러리 빌드를 통과했습니다.
새 테스트는 이른 완료·동일 종류 요청의 응답 역전·프로젝트 교체·제거된 작업 대기·
늦은 초기 목록·늦은 실제 시작 알림을 다룹니다. 서비스의 전체 테스트와
타입 바인딩 검사도 별도로 통과했습니다.

실제 네이티브 창에서 장시간 반복 실행한 RSS나 렌더링 지연은 측정하지 않았습니다.
전송 JSON과 합성 V8 힙 모델은 [성능 기록](compact-ipc.md)에 범위를 구분해 적었습니다.

판정: **Approve**. 이 검토 범위에 남은 HIGH·MEDIUM 항목은 없습니다.
