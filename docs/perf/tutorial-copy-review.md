# P59 화면 문구 검토

## 범위

Full 모드. React와 기존 CSS, 한국어·영어 카탈로그의 튜토리얼,
연결표 저장 조작, 계산 오류 안내와 P60 샘플레이트 선택을 검토합니다.
사용자 지적 A~E를 기준으로 실제 동작과 화면 문구를 대조합니다.

| 항목 | 검토 근거 | 결과 |
|---|---|---|
| 글쓰기 | 카탈로그, 튜토리얼 자동 실행, 기본값 적용, CSV 저장, 엔진 오류 | 아래 수정 |
| 타이포그래피 | 1024×700·1280×800, 두 언어·두 테마의 실제 렌더링 | 72개 화면 확인, 새 펼침 라벨 14px |

## 검토 후 유지한 사항

- 좁고 깊은 응답 딥을 '채우다'라고 하는 용례는 입력란의 fill 직역과 달라 유지합니다.
- 파일 이름 접미사는 mdat 도움말의 참고 정보에 유지합니다.
  튜토리얼의 주 설명에서는 파일 사용 목적을 먼저 제시합니다.
- 측정 방식의 정식 이름 '모의 측정'은 용어표와 일치하도록 유지합니다.
- 일반 계산 오류에서 원문 문자열을 파싱해 원인을 추측하는 방식은 사용하지 않습니다.
  구조화된 원인과 값이 없는 오류는 기존 상세 정보로 확인합니다.

## 한국어 윤문 감사

기존 튜토리얼 본문·이유와 수정한 기존 문구 81키를 원본과 비교했습니다.
원본 카탈로그 대비 55키가 바뀌었고, 이 중 요청으로 추가한 도움말·오류·정책
문구는 22키입니다. 기존 문구의 문자 변경률은 8.10%, 보호 토큰 119개는
모두 보존됐습니다.

스킬 자동 감사의 원래 등급은 D입니다. 변경하지 않은 실제 라벨 인용
`'2–3인 소파'`의 대시를 검사기가 인용문으로 구별하지 못해 실패했습니다.
실제 라벨 보존 원칙에 따라 인용을 유지하고, 자동 D 결과와 수동 예외 판정을
함께 기록했습니다. 서법 감소 경고는
사용자가 수정하도록 지적한 모의 측정의 무관한 선행 조건과 '넘어갈 수 있습니다'
등을 실제 목적·행동 안내로 교체한 부분입니다.

## 검증과 판정

- 조정자 `npm ci`, 타입 검사, UI 490개 검사(50파일), 앱·갤러리 빌드 통과.
- 한국어·영어, 밝은·어두운 테마, 1024×700·1280×800의 8변형에서 72개 캡처와
  조작 확인. 모의 측정의 이유·두 번 누르기 안내, mdat 안내, CSV 용도,
  실제 오류에서 정책 펼치기, 키보드 정책 선택·화면 복귀 후 복원을 확인했습니다.
- 좁은 영문 작업 트레이에서 취소 버튼을 실제로 클릭했습니다.
- 펼침 버튼은 32px 외형에 확장 클릭 영역 40px입니다. 외형 위쪽 2px 지점을
  눌러 실제 토글되는 것을 확인했습니다. 화살표는 10% 재생 속도로 검사했습니다.
- 한국어 자동 감사의 인용 라벨 대시 예외는 위에 기록했습니다.

- 최종 전체 갤러리 54장면 × 4변형, 216장 촬영 통과.
- 촬영용 loopback HTML에 AdGuard 스크립트가 삽입되는 현상과 Chromium의
  새 페이지 생성 대기를 각각 확인했습니다. 촬영 브라우저는 해당 빌드 origin만
  로컬 파일로 응답받고, 테마·언어별 페이지에서 각 장면을 전체 탐색으로 다시
  로드합니다. 단계별 상한과 요청 URL 진단을 추가했습니다. 이 조건에서 216장,
  별도의 72개 조작 확인과 색상·동작 효과 검사를 다시 통과했습니다.
