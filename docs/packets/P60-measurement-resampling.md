# P60. 측정 샘플레이트 처리 선택

## 요청

고급 설정에서 샘플레이트 불일치 시 기존처럼 계산을 중단하거나 리샘플링하도록
선택합니다. 원작도 불일치를 거부하는지 함께 조사합니다.

## 원작 확인

고정한 업스트림의 `src/secs/correction_engine.py:491~498`은 기준 위치의 IR이
48 kHz가 아니면 오류를 냅니다. 다른 위치는 508~513에서 입력 샘플레이트를
변환하지 않고 고정 48 kHz로 취급합니다. Rust는 기존 편차 D2에 따라 모든
위치를 검사합니다.

## 계약

- `SampleRatePolicy`는 `Reject`와 `Resample`이며 기본값은 `Reject`입니다.
- `CalibrationSettings.sample_rate_policy`는 누락 시 기본값으로 읽습니다.
  IPC에서는 기본값도 명시적으로 보냅니다.
- `SettingEdit::SampleRatePolicy { policy }`로 기존 설정 수정 경로를 사용합니다.
- `.secs` 파일은 이 설정을 보존합니다. 기본값은 새 키를 생략해 기존 파일
  바이트 호환을 유지합니다. 이전 파일은 계산 중단으로 읽습니다.
- 기본 정책의 엔진 지문은 기존과 같습니다. 리샘플링 선택 시 별도 지문을
  사용하고, 정책을 바꾸면 보정과 MIMO 결과의 낡음을 다시 판정합니다.
- 원본 측정 샘플, 원본 `t0`, `.irs` WAV와 측정 기록은 바꾸지 않습니다.
  변환은 계산용 데이터에만 적용합니다.
- 48 kHz 입력은 변환하지 않으며 기존 결과와 같은 비트를 유지합니다.
- 다른 레이트는 앨리어싱을 억제하는 필터를 거쳐 48 kHz로 변환합니다.
  IR의 전달함수 크기와 물리적 도착 시각을 보존하도록 정규화와 시간 원점을
  정의합니다. 일반 오디오 파형의 진폭 보존과 IR 계수의 합 보존을 구별합니다.
- 길이 계산의 넘침과 메모리 사용을 확인하고 긴 변환은 취소할 수 있어야 합니다.
- 보정, 서브만 계산, XO 추천, MIMO, 결과 그래프와 내보내기는 동일한
  계산용 측정을 사용합니다.
- 화면 선택지는 '계산 중단'과 '48 kHz로 변환'처럼 실제 효과를 표현합니다.
  원본 보존과 적용 범위는 해당 항목의 도움말에 적습니다.

## 준비 경계

`normalize_measurements(&MeasurementSet, SampleRatePolicy, &Context)`는
`Result<MeasurementSet, EngineError>`를 반환합니다. `engine_inputs`의
가벼운 설정 해석과 역할 선별은 유지합니다.

- 보정 작업 클로저에서 변환한 뒤 `DesignRequest`와 `CalibrationRun`이
  그 측정을 사용합니다. MIMO는 해당 결과에 보관된 계산용 측정을 받습니다.
- XO 추천은 역할 선별 뒤, 후보별 계산 전에 한 번 변환합니다.
- 캐시에서 내보낼 때는 작업 클로저 안에서 세션 잠금을 해제한 뒤 변환합니다.
  `CachedRunLabels.sample_rate_policy`로 계산 당시 정책을 복원하며, 이 값이
  없는 기존 캐시는 `Reject`로 읽습니다.
- 변환 단계의 새 출력과 임시 메모리를 예산으로 확인합니다. 변환 permit은
  반환 전에 해제해 다음 계산의 permit과 서로 기다리지 않도록 합니다.
  반환된 샘플은 기존 엔진의 보관된 입력 메모리 규칙을 따릅니다.
- 중앙 정렬 FIR의 양끝 응답을 보존합니다. 계산용 `t0`를 선행 출력 시간만큼
  조정해 필터 지연을 보상합니다. 원본의 `t0`는 그대로입니다.

업스트림 트리와 기존 골든 파일은 수정하지 않습니다.

## 검증

- 48 kHz의 기존 비트와 기본 거부 동작.
- 44.1/88.2/96/192 kHz 입력의 48 kHz 변환, 혼합 레이트의 여러 위치.
- IR 크기·지연·양끝 경계·앨리어싱·출력 길이, 잘못된 입력과 취소.
- 프로젝트 왕복과 이전 파일 기본값, 정책 변경 시 결과·캐시 낡음.
- 원본 샘플/원점/파일 해시 보존과 변환 후 보정·내보내기.
- 실제 고급 선택지의 키보드 조작, 오류에서 해당 설정 접근, 언어·테마별 화면.
