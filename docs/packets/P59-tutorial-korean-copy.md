# P59. 튜토리얼 행동 안내와 한국어 문구

## 요청과 범위

사용자가 지적한 '채우다', '채우고 넘어갑니다'를 문맥에 맞는 동사로 고칩니다.
튜토리얼의 모의 측정 선택은 소리가 나지 않는 현상만 설명하지 않고,
스피커로 소리를 재생하지 않고 측정 절차를 연습하려는 목적을 밝힙니다.
다른 튜토리얼도 행동 안내와 '이유'가 호응하는지 검토합니다.
추가 지적 C~E도 함께 다룹니다. REW mdat 저장 안내는 비교할 내용과 사용할
프로그램을 먼저 설명하고, 출력 패치 CSV는 파일의 용도가 드러나게 고칩니다.
XO 추천 오류는 실패 원인을 실제 발생 조건에 맞게 전달합니다.

## 계약

- 설정 적용, 값 입력, 데이터 불러오기, 화면 이동을 구별합니다.
- '계속' 두 번의 자동 실행은 값 입력뿐 아니라 탭 열기와 계산 시작도 포함합니다.
  문구는 실제 동작 범위를 설명하며 완료되지 않은 작업의 완료를 약속하지 않습니다.
- 모의 측정은 소리 출력 문제를 진단하는 방법으로 안내하지 않습니다.
- 실제 장비에서의 레벨 점검 설명과 튜토리얼 예시 동작을 구별합니다.
- 실제 튜토리얼의 설명 단계 30개와 견본의 설명 단계 3개를 클릭 허용 범위와
  대조합니다. 보기만 하는 단계는 기능과 효과를 설명하고, 현재 허용된 조작에만
  실행 지시를 씁니다. 내보내기 이동 단계의 추가 재계산 지시도 같은 기준을 따릅니다.
- 카탈로그 키와 보간 인자, 기능과 튜토리얼 순서는 유지합니다.
- 관련 영어 문구는 같은 의미를 전달하도록 함께 검토합니다.
- 물리적 현상 등 '채우다'의 다른 용례는 문맥으로 판단합니다.
- 저장 안내는 파일의 용도를 설명하며, 파일 이름 접미사 규칙을 튜토리얼의
  주 설명으로 쓰지 않습니다.
- 계산 실패를 모두 측정 오류로 표현하지 않습니다. 구조화된 원인 정보가
  있으면 원인과 다음 행동에 사용하고, 원문 해석으로 원인을 추측하지 않습니다.

## 소유권

- iir_profile: ko/en 카탈로그, 기존 테스트의 문구 참조 수정, 문구별 근거 기록.
- gpu_service_cli: CSV와 오류 발생 조건 조사. 구현은 추가 계약 확정 후 진행.
- gpu_ui: CSV 저장 조작의 라벨과 도움말 배치. 구현은 추가 계약 확정 후 진행.
- 조정자: 작업서, 변경 기록, 독립 검증과 리뷰, 커밋과 PR.
- 로직 변경이 필요하면 구현 전에 조정자에게 보고합니다.

## E 오류 전달 계약

엔진의 계산 방법과 실패 조건은 유지합니다. 측정 검증에서 이미 알고 있는 값을
문자열에서 다시 추출하지 않고, 다음 오류 변형과 IPC 매개변수로 전달합니다.
IPC 오류 코드는 기존 `engine_input`을 유지합니다.

| 엔진 오류 | `params.reason` | 추가 매개변수 |
|---|---|---|
| `MeasurementSampleRate` | `measurement_sample_rate` | `position`, `role`, `actual_hz`, `expected_hz` |
| `InvalidMeasurement` | `invalid_measurement` | `position`, `role` |
| `DuplicateMeasurement` | `duplicate_measurement` | `position`, `role` |
| `MissingReferencePosition` | `missing_reference_position` | `position` |
| `MissingMainMeasurement` | `missing_main_measurement` | `position` |

위치와 주파수는 `u32`, 역할은 `String`입니다. IPC에서는 기존 매개변수 형식인
문자열로 전달합니다. 진단 원문은 기존 `detail`에 보존합니다.
화면은 알고 있는 reason과 필요한 값이 모두 있을 때만 구체적인 원인과
다음 행동을 번역합니다. 누락·미지정 reason은 일반 계산 실패로 표시하며,
측정 오류라고 단정하거나 미치환 자리표시자를 노출하지 않습니다.

XO 후보가 없다는 기존 갤러리 오류는 실제 엔진 조건이 아니므로 삭제합니다.
실제 측정 검증에서 발생하는 샘플레이트 오류를 갤러리와 오류 견본에 사용합니다.
계산 실패 문구는 작업 이름과 원인을 한 번씩 표시합니다.
알려진 측정 오류에는 '측정 데이터 확인' 버튼을 제공하고, 기존 화면 이동
경로를 재사용해 측정 위치 목록을 엽니다. 미분류 오류에는 이 버튼을 붙이지
않습니다. 갤러리 mock의 실패 주입은 선택적 매개변수 인자를 추가해 실제
서비스와 같은 오류 봉투를 재현합니다.

추가 소유권:

- gpu_service_cli: 위 엔진 오류 변형과 발생 지점, 서비스 변환, 관련 검증.
- gpu_ui: 공통 오류 번역과 실패 문구 조합, 관련 UI 검사, 오류 견본과 갤러리,
  mock의 선택적 오류 매개변수, 측정 위치 목록으로 이동하는 좁은 화면 연결.
- iir_profile: 오류 카탈로그 키와 번역. 다른 워커와 키를 먼저 합의합니다.

## 검증

카탈로그 키/보간 검사, 기존 튜토리얼 동작 검사, 타입 검사, UI 빌드와
변경 문구가 표시되는 화면을 확인합니다. 저장소 공통 게이트와 PR CI를 따릅니다.
