# P62 (Daybreak Blue): the `skin` app setting

Worktree: `/home/user/wt/p62` (branch `wt/p62`). Do not commit; Claude
reviews the diff and commits. Use absolute paths. Node is not needed.

SECS 2R gets skin sets (ADR 0010, `docs/skins/`): the default skin and two
alternatives, `rack` and `matrix`. The screen applies the choice as
`data-skin` on `<html>`; this packet adds the setting the screen reads and
writes, next to `theme` and `icon`, so the choice survives a restart.

Read first: `CLAUDE.md`, `docs/adr/0003-stack-and-ipc.md` (IPC types live in
`secs-types`; bindings are generated by its tests), the `AppTheme` and
`AppIcon` enums and `AppSettings` in `crates/secs-types/src/ipc.rs`, and
`app_settings_get`/`app_settings_set`/`load_app_settings` in
`crates/secs-service/src/project_edit.rs`.

## What you add

1. **`AppSkin`** in `crates/secs-types/src/ipc.rs`, right after `AppTheme`,
   with the same derives and `#[serde(rename_all = "snake_case")]`,
   `#[ts(export)]`, `Default` on the first variant:

   ```rust
   /// The skin set the screen draws with (docs/skins, ADR 0010).
   #[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize, TS, Default)]
   #[serde(rename_all = "snake_case")]
   #[ts(export)]
   pub enum AppSkin {
       /// The instrument skin: the default tokens.
       #[default]
       Default,
       /// Hardware Rack: a 19-inch rack faceplate.
       Rack,
       /// Signal Matrix: a routing board of cells on a grid.
       Matrix,
   }
   ```

   Serialized values are exactly `default`, `rack`, `matrix`.
2. **`AppSettings.skin: AppSkin`** with `#[serde(default)]` (an old
   settings file without the field loads as `Default`), documented like the
   neighbours ("Skin set the screen draws with."), placed after `icon`. Add
   it to `impl Default for AppSettings`. Fix every `AppSettings { .. }`
   struct literal the build finds (`crates/secs-service/tests/compute.rs`,
   `config.rs`, `service.rs`, and anything else `cargo test --workspace
   --no-run` reports). Do not change the sanitising in `app_settings_set`
   (there is nothing to sanitise in an enum).
3. **The service test.** Extend
   `app_settings_are_versioned_bounded_and_capped` in
   `crates/secs-service/tests/config.rs`: the saved settings use
   `skin: AppSkin::Rack` and must come back as `Rack` after reopening; the
   old-format file (the `version: 1` fixture that has no `skin`) must load
   as `AppSkin::Default`.
4. **Bindings.** `cargo test -p secs-types --locked` writes
   `apps/secs2r/ui/src/ipc/bindings/AppSkin.ts` and updates
