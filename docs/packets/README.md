# 작업서

워커(ASTRA, Daybreak Blue, Opus 5.5)에게 넘기는 구현 단위입니다. 파일 이름은 `<번호>-<워커>-<주제>.md`(예: `P01-astra-jos.md`)입니다. 한 작업서는 다음을 담습니다.

- 목표와 끝나는 조건(통과해야 하는 테스트와 골든)
- 고쳐도 되는 파일 목록과 다른 워커가 쥔 파일(겹치지 않게). 워커는 자기 워크트리에서 일하므로 `Cargo.lock`은 cargo가 고치는 범위에서 늘 허용하고, 머지할 때 Claude가 다시 생성합니다.
- 지킬 계약: 시그니처, 오류 정책, 결정성 규칙(ADR 0007), unsafe 금지(ADR 0002)
- 이식할 업스트림 파일과 함수(`src/secs/...`), 맞출 골든
- 포그라운드로 돌릴 검증 명령과, 명령이 끝나기 전에 턴을 끝내지 말 것
- 보고 형식(바꾼 파일, 통과한 명령의 출력, 남은 문제)

워커의 자기 보고는 게이트가 아닙니다. Claude가 디프를 검토하고 검사를 다시 돌린 뒤 커밋합니다.
