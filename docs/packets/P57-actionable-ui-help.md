# P57 — 설명 대신 동작으로 연결하는 화면

## 요청과 원인

측정 출력 장치의 `고르지 않음 · 연결·점검에서 고르세요`는 상태와 이동 방법을
문장으로 붙여 둔 것입니다. 시작 도움말은 테마 색, 프로젝트 처리, 저장 제한 등
현재 조작에 필요하지 않은 동작 설명으로 길어졌습니다. 같은 패턴을 화면 전체에서
점검하고, 설정 이동은 동작으로 연결하며 불필요한 설명은 삭제합니다.

## 계약

- 미선택 장치는 짧은 경고 상태(예: `미선택`)와 warning 삼각 아이콘으로 표시합니다.
  경고는 기존 색 토큰으로 글자·아이콘에 적용하고 새 경고 배너나 채운 박스를 만들지 않습니다.
- 옆의 `설정하기` 버튼은 연결·점검의 실제 설정 위치로 이동합니다. 장치 선택이 있는
  방식이면 출력 장치 선택 칸에 초점과 스크롤을 맞춥니다. 방식 미선택이면 방식 선택으로
  연결합니다. REW 소유 장치·mdat·모의 측정 등 장치 선택이 적용되지 않는 경로도 구분합니다.
  임의로 측정 방식을 바꾸거나 장치를 자동 선택하지 않습니다.
- native의 빈 출력 선택은 OS 기본 장치입니다. 미선택과 구분해 중립 상태로 표시하며,
  예전 config.device를 빈 선택의 대체값으로 사용하지 않습니다. mock/mdat에는 장치 행이 필요하지 않습니다.
- 정상 상태는 선택 장치와 실제 출력 수를 보여 줍니다. 채널 초과·장치 확인 중·미선택을
  혼동하지 않으며, 설정 변경 후 시스템 화면은 실제 상태를 반영합니다.
- 시작 안내는 짧은 용도 설명과 튜토리얼 시작 동작 중심으로 구성합니다. 테마 변경,
  프로젝트를 따로 여는 내부 절차, 중복 흐름 목록과 REW 요구 조건의 무관한 나열은 제거합니다.
- UI의 내부 동작 해명·방어·자명한 조작 설명은 도움말로 다시 쌓지 않고 삭제합니다.
  꼭 필요한 제한과 오류는 해당 상태에서 짧게 표시합니다. 도메인 참고 자료와 실제
  오류 원인, 복구 행동, 데이터 손실 확인은 보존합니다.
- 앱 안에서 해결할 수 있는 문장형 길안내는 해당 위치의 동작이나 직접 이동으로 대체합니다.
  앱 밖(REW·OS·DSP)의 실제 조작 절차는 필요한 범위에서 유지합니다.
- 모든 변경은 ko/en에 함께 적용합니다. React/기존 CSS 토큰, UI 14px 이상,
  누름 영역 40px 이상, 도움말의 P56 투명 아이콘 스타일을 유지합니다.
- 엔진·IPC·업스트림 Python은 변경하지 않습니다. 튜토리얼, 검색, 키보드 조작 기능을 유지합니다.

## 소유권

- 조정자: 작업서·설계 결정, 변경 기록, full 리뷰 기록, 독립 검증, 커밋/PR/머지/릴리스.
- UI 워커: SystemScreen/시스템 CSS 및 관련 뷰 테스트·견본, help 폴더의 뷰/구조/테스트,
  ProjectDialogs·MeasureScreen·ExportScreen·menus의 불필요한 설명 참조, StepHeader/AppFrame의 복구 버튼 뷰.
- 연결·문구 워커: App/host의 필요한 탐색 연결, 시스템 hook/types의 계약,
  ko/en 카탈로그와 관련 통합 테스트. UI 워커와 콜백/키를 먼저 합의합니다.
- 읽기 전용 감사 워커: 전 화면 문구·도움말에서 삭제할 내부 해명과 동작으로 대체할
  길안내 목록, 측정 방식별 장치 상태 근거. 직접 수정하지 않습니다.

## 검증

- 미선택/선택/초과, native/REW/mock/mdat/방식 없음, 이동·초점·왕복 상태 반영을 확인합니다.
- 도움말 시작/검색/탭/튜토리얼 시작/종료, 실제 오류·데이터 손실 확인을 유지합니다.
- ko/en × 밝게/어둡게 × 1280×800/1024×700에서 실제 화면과 필요한 견본을 확인합니다.
- 저장소 필수 게이트와 전체 화면 tour, 변경된 상호작용을 조정자가 독립 실행합니다.
- make-interfaces-feel-better full 범위: 장치 예외와 이동 흐름, 도움말 구조,
  감사에서 실제 수정한 정적 안내. 근거 없는 설명을 더하는 변경은 완료로 보지 않습니다.
