# P56 — 읽자마자 이해하는 보정 요약

## 문제와 범위

P55의 계산 전 카드가 `측정 위치 1곳으로 보정 · 서브 3대 정렬·크로스오버 포함`,
`추가 시간 소요`, `RC IIR + FIR 2,048탭 · MIMO IIR`처럼 문장을 축약했습니다.
사용자는 이 내용을 해석해야 한다고 지적했습니다. 길이를 줄이는 대신 대상과 동작을
바로 알 수 있게 다시 구성합니다. 계산 전 요약, 바로 아래 모드 설명과 대응 ko/en만
고치고, 추가 요청에 따라 공통 도움말 아이콘의 장식을 정리합니다. 결과 수치, 계산 동작, 엔진·IPC·업스트림 코드는 유지합니다.

## 계약

- 결과가 없는 카드의 제목은 앞으로 할 일을 나타냅니다. 이미 나온 결과의 제목과 구분합니다.
- 계산 전 본문은 측정 위치 수를 사용한 완결 문장 하나로 씁니다. 서브우퍼의 상세 설정은
  기존 설정 영역에서 다룹니다. 구성 대수와 실제 측정 대수를 혼동하는 별도 요약은 없앱니다.
- 크로스오버 자동 추천·추가 시간 문장은 삭제합니다. 실제 `calibrate`는 추천을 실행하지
  않고 선택값, 프로젝트 값, 기본 80 Hz 순으로 사용합니다. 추천은 기존 별도 버튼에서
  실행하므로 요약에 새로운 지시나 중복 안내를 넣지 않습니다.
- 계산 전 카드에서 모드의 기술 사양을 반복하지 않습니다. 모드 선택 영역에는
  사용자에게 영향을 주는 추가 지연을 보여 줍니다. IIR/FIR/탭 수 등 상세는 명확한
  이름의 도움말에서 확인합니다. MIMO가 꺼져 있는데 실행 예정으로 읽히면 안 됩니다.
- 일반 도움말도 압축된 명사 목록으로 바꾸지 않습니다. 같은 사실을 본문과 도움말에
  중복하지 않습니다. 한국어 합니다체, 완결 템플릿, 영어 단복수 및 의미 일치.
- `max_latency_ms`는 자동 보정의 추가 지연 한도입니다. 수동 딜레이와 장치 지연을 포함한
  실제 재생 지연 상한으로 표현하지 않습니다. `mode_spec.mimo_filter`는 항상 IIR을
  반환하므로 현재 MIMO 동작을 나타내는 문구로 쓰지 않습니다.
- 측정 없음, 실패·복구, 오래된 결과, 실제 결과 모드·지연 표시는 보존합니다.
- 기존 React/CSS 토큰, 14px 하한과 40px 도움말 영역을 사용합니다. 새 의존성 없음.

## 추가 요청 — 도움말 아이콘의 버튼 장식 제거

사용자가 도움말 주위의 청록색 사각형과 라벨에 붙는 테두리를 지적했습니다.
공통 HelpTip에서 배경 채움, 사각 테두리, 선택 상태 및 눌림 확대·축소를 없앱니다.
마우스를 올리면 아이콘 옆에 설명만 나타나고, 클릭 후에도 사각형이 남지 않아야 합니다.
40px 누름 영역은 보이지 않게 유지하고, 라벨과 아이콘 사이에 간격을 확보합니다.
키보드 초점 표시는 아이콘 자체에 한정해 사각형 없이 구분합니다.
일반 버튼의 초점 표시는 바꾸지 않습니다.

## 소유권

- 조정자: 작업서, 변경 기록, 검토 기록, 독립 검증, 커밋·PR·병합·릴리스.
- UI 워커: `screens/calibrate/Results.tsx`, `Settings.tsx`, `text.ts`, 관련 CSS·기존
  화면 테스트·갤러리 장면. 카탈로그는 수정하지 않습니다.
- 추가 요청은 공통 `ui/ui.css`와 필요한 HelpTip 검증까지 UI 워커가 맡습니다.
- 문구 워커: `src/i18n/ko.json`, `en.json`. 키 계약을 UI 워커와 맞춥니다.
- 도메인 검토 워커: 서브 정렬·XO 추천·모드 지연의 실제 동작 읽기 전용 검토.

## 검증

- ko/en, 밝게/어둡게, 1280×800 및 1024×700에서 수정 카드와 모드 영역을 직접 확인합니다.
- 위치 0/1/여러 곳, 서브 0/1/여러 대, XO 추천 있음/없음, 네 모드, MIMO 켜짐/꺼짐,
  실패·현재·오래된 결과를 확인합니다. 문구만 복제하는 새 테스트는 만들지 않고 기존
  상태 검증을 조정합니다. 필요한 조건부 표시 회귀만 추가합니다.
- 카탈로그·타입 검사·UI 테스트·앱과 갤러리 빌드 및 저장소 필수 게이트를 재실행합니다.
- `make-interfaces-feel-better` full 검토 범위는 위 두 영역과 공통 도움말 아이콘입니다. 독자가 추가 설명 없이
  대상과 동작을 말할 수 있는지 검토하고, 기술 목록 숨기기만 한 문구는 통과시키지 않습니다.
