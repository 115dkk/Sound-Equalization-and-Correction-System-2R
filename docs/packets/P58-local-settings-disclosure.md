# P58 — 전역 전문가 표시를 없애고 설정을 제자리에 공개

## 요청과 확인

사용자는 숙련도에 따라 설정 접근을 제한하는 개념을 원하지 않습니다. 로고의
‘전문가 모드 / 킹반인 모드’는 커뮤니티 농담이며, 설정 접근과는 관계가 없습니다.
기존 전역 스위치는 초고지연 모드, 자체 측정의 장치 공유 방식, 밴드 열과
파일상 채널 이름을 숨깁니다. 엔진 튜닝 항목 전체를 공개하는 기능은 아닙니다.

## 계약

- 설정 패널의 ‘전문가 항목 표시’와 전역 `Prefs.expert` 상태를 제거합니다.
  `AppSettings.expert_display`도 저장·IPC 계약에서 제거하되 기존 JSON의
  true/false 값은 무시하여 다른 설정을 정상적으로 읽습니다.
- 로고 선택의 두 이미지·이름·기본값·저장은 유지합니다. 로고는 설정의 노출이나
  계산 값을 바꾸지 않습니다. 농담에 대한 해명 문구를 화면에 추가하지 않습니다.
- 보정 모드는 네 가지를 같은 선택 목록에서 제공합니다. 초고지연의 지연 값은
  초고지연을 선택했을 때 현재 위치에 표시합니다. 기존 프로젝트 값을 보존합니다.
- 자체 측정의 장치 공유 방식은 장치 카드의 지역 disclosure에서 펼칩니다.
  제목은 내용인 ‘장치 공유 방식’으로 쓰고, 기존 공용 disclosure를 재사용합니다.
  자동/독점/공유 선택과 실제 설정 호출을 보존하며 REW에는 나타나지 않습니다.
- 시스템의 밴드 정보는 이미 있는 스피커 상세 보기에서 제공합니다. 전역 스위치로
  나타나던 중복 밴드 열은 없애고, 파일상 채널 이름도 해당 상세 도움말에서
  모든 사용자에게 제공합니다. 채널 선택·다중 밴드·출력·극성 정보를 보존합니다.
- 화면, 도움말, 오류 안내, 테스트, 견본·tour에서 전역 전문가 설정으로 보내는
  참조를 없앱니다. 관련 없는 기존 지역 ‘고급’은 유지합니다.
- ko/en, 기존 React/CSS 토큰, 14px UI 글자와 40px 조작 영역을 유지합니다.
  엔진·프로젝트·오디오 실행 의미와 업스트림 Python은 변경하지 않습니다.

## 소유권

- 조정자: 작업서·아키텍처·편차·변경 기록, `secs-types` 시그니처,
  full 리뷰 및 독립 게이트, 커밋·PR·병합·배포.
- UI 워커: `app/menus.tsx`, `ui/Card.tsx`, system/connect/calibrate 뷰와
  해당 뷰 테스트·견본, 필요 CSS. 전역 preference 정의·카탈로그는 건드리지 않습니다.
- 연결·문구 워커: `App.tsx`, `app/prefs.tsx`, ko/en, IPC fixtures,
  나머지 테스트·견본·gallery/tour의 전역 expert 상태 제거, 통합 테스트.
- 서비스 워커: AppSettings 변경에 따른 서비스 테스트와 과거 설정 JSON 읽기·재저장
  검증. 생성 바인딩은 시그니처 변경 뒤 `cargo test -p secs-types`로 갱신합니다.

## 검증

- 이전 설정 파일의 expert_display true/false 모두 로드, 기존 언어·테마·로고·최근
  프로젝트 유지, 재저장 시 폐기 필드 제외.
- 로고 두 종류를 바꿔도 사용 가능한 설정과 프로젝트 값 동일.
- 전역 스위치 없이 초고지연 선택·지연 변경, 장치 공유 disclosure 열기·키보드
  조작·값 반영, REW에서는 자체 장치 설정 미노출.
- 시스템 채널 상세의 다중 밴드·파일상 이름, 기존 오류/복구/도움말 동작.
- ko/en × 밝게/어둡게 × 1280×800/1024×700 화면 검증, 전체 tour,
  저장소 필수 Rust/Python/UI 게이트 및 PR CI·릴리스 자산 확인.
