# P61. Equalizer APO 채널 할당 문법 수정

## 요청과 재현

원작의 Equalizer APO FIR 내보내기가 적용되지 않는다는 제보를 재현하고,
SECS 2R과 EqualizerAPO-XT 중 결함이 있는 쪽을 수정합니다.

고정한 원작의 공개 `export_eqapo`로 만든 스테레오 FIR과 게인 전용 설정을
EqualizerAPO-XT `3a6a213c`의 실제 FilterEngine/Benchmark에서 실행했습니다.
`Eval: inL = 1; inR = 2`와 출력 할당에서 muparserx가 세미콜론을 거부하고,
이어지는 채널 조건도 실패하여 보정이 적용되지 않습니다. 전역 Preamp가
0 dB인 최소 사례에서는 입력과 출력이 같습니다. 모노 FIR은 정상입니다.
각 할당을 별도의 `Eval:` 줄로 바꾸면 같은 WAV로 기대한 FIR/게인이 적용됩니다.
조정자가 28회 대조 실행을 독립적으로 다시 수행했습니다.

## 계약

- `secs-filters::eqapo_config`는 입력 역할 순서, 이어서 출력 역할 순서로
  변수마다 하나의 `Eval:` 명령을 만듭니다. 변수 이름과 번호는 보존합니다.
- 모든 할당은 채널 조건과 Copy 명령보다 앞에 둡니다.
- 설정 머리와 적용 안내의 '두 줄' 및 세미콜론 예시를 새 문법에 맞춥니다.
- FIR 계수·WAV 형식·샘플레이트·필터 본문·상대 경로·게인·라우팅은 보존합니다.
- 기존 오라클과 보호된 파이썬 트리는 그대로 둡니다. 테스트 기대값에서
  문서화한 F11의 정확한 설정/안내 변경만 반영하며 나머지 바이트를 비교합니다.
- 추가 검증에서 원본 APO가 지정한 muparserx 3.0.1은 세미콜론을 받아들이고
  XT의 4.0.12는 거부함을 확인했습니다. SECS 2R은 버전 공통 문법으로
  내보내고, XT에는 기존 원작 파일을 읽는 구형 문법 호환 수정을 함께 넣습니다.

## 소유권

- 조정자: 작업서, 편차 F11, 기능 등록, 변경 기록, 상호운용 결과 문서,
  독립 게이트, 디프 검토, 커밋·PR·릴리스 확인.
- iir_profile: `crates/secs-filters/src/lib.rs`와 해당 크레이트 테스트의
  최소 수정, 실제 Rust 작성기로 만든 소비자 검증용 파일.
- gpu_service_cli: 별도 XT 작업 트리에서 소비자 조사, 외부 재현 자료와
  `docs/architecture/legacy-expression-separators.md`의 계약에 따른
  파서 호환 및 회귀 검증 구현.

다른 작업자의 변경을 되돌리지 않습니다. 실제 PC의 오디오 장치 설정은
이 재현에 필요하지 않습니다.

## 검증

- 스테레오·2.1의 정확한 할당 순서/값, 모노, 0 매핑, 대소문자 구별 역할.
- 기존 직접 작성기와 공개 내보내기·계산 결과 골든: F11 이외 바이트 보존.
- 실제 XT 엔진의 원작/수정본 비교: 채널별 임펄스와 서로 다른 FIR, 게인 전용,
  2.1, 실제 계산 사례. PCM16 출력은 양자화 간격을 허용오차로 사용합니다.
- 48 kHz 및 불일치 레이트, 상대 경로, 부족한 장치 채널은 별도로 판정합니다.
- 수정한 Rust 작성기의 실제 출력도 소비자에 넣어 확인합니다.
- 저장소 전체 필수 게이트와 CI를 통과한 뒤 기본 릴리스 절차를 따릅니다.
