# P54. 화면 결과 경량화와 완료 작업 수명

기준: `codex/compact-result-ipc`, main `d8e0bd6` (0.20.0).
결정: ADR 0009. 원래 E: 체크아웃과 upstream Python 트리는 수정하지 않습니다.

## 소유와 계약

- 조정자: `secs-types`와 생성 바인딩, ADR·작업서·문서·기능 등록부,
  최종 검증·커밋·PR·머지·릴리스 확인.
- 서비스 워커: `crates/secs-service/**`, `apps/secs2r-cli/**`.
- 화면 워커: `apps/secs2r/ui/src/**` 중 생성 바인딩 제외. 기존 화면 표시를
  유지하고 세션·목록·모의 서비스·견본·테스트를 함께 고칩니다.
- 감사 워커: 작업 공간 밖의 전후 JSON·힙 측정 자료. 코드 소유권은 없습니다.

공유 작업 공간입니다. 다른 담당자의 변경을 되돌리지 않으며 커밋은 조정자가 합니다.

`CalibrationSummary.chain`을 제거하고 `main_roles`, `sub_roles: Vec<String>`을
더합니다. `MimoSummary.paths`를 제거하고 `input_count: usize`를 더합니다.
`JobResult::Calibration`과 `JobResult::Mimo`는 단위 변형입니다.
`JobSnapshot.result`는 제거합니다. 완료 이벤트의 다른 작은 결과 값은 유지합니다.

완료 잡은 Rust·화면에서 최근 32개만 남기고 모든 활성 잡은 보존합니다.
이력은 앱 전체에서 위 상한으로 유지하고 완료 요청은 즉시 정리하며, 조기 완료와 중복 이벤트,
비동기 초기 목록 조회가 수명이 끝난 기록을 되살리는 경우를 검증합니다.
화면 요약은 계수 배열을 포함하지 않고, 내보내기와 캐시에는 원본을 유지합니다.
이전 v2/v3 캐시를 새 내부 형태로 읽습니다. 대형 FIR 원본을 보존하도록 캐시 상한은
64 MiB이며 크기 제한 임시 파일로 직접 직렬화합니다. 세션·결과 잠금은 파일 쓰기 전에
해제하고, 이전 프로젝트에서 시작한 작업은 새 프로젝트에 결과를 커밋하지 않습니다.

## 완료 조건

- 대형 FIR 요약의 직렬화 크기가 탭 배열 크기에 따라 증가하지 않습니다.
- 완료 이벤트와 작업 목록에 보정·MIMO 요약/계수 원본이 없습니다.
- 반복 완료 후 기록 상한, 활성 잡 보존, 프로젝트 교체, 조기 완료가 통과합니다.
- 이전 캐시 재열기 및 Rust 파일 내보내기가 원래 필터를 유지합니다.
- 저장소 필수 게이트와 PR CI 통과 후 머지하며 릴리스 실행을 확인합니다.
