
# 변경 기록

번호는 A.B.C 입니다. A = 이전 판과 호환되지 않는 변경, B = 기능 추가, C = 버그 수정.

## SECS 2 Beta 1.3.1 — 2026-10-17

REW mdat 내보내기

- 내보낸 mdat 의 측정 정보(마이크 캘 · 오디오 장치 · 측정 날짜)가 원 측정과 다르게 들어가던 문제를 고쳤습니다. 측정값(IR)은 원래대로 같습니다.
- 보정 전 측정은 원 측정의 정보를 그대로, 보정 후 측정은 REW '형식' 칸에 SECS2 계산값이라고 표시합니다.

## SECS 2 Beta 1.3.0 — 2026-10-15

내보내기

- 내보내기 화면의 REW mdat 아래에 '필터 내보내기' 를 새로 만들었습니다: CamillaDSP · 텍스트 · EqAPO.
- 텍스트로 내보내기: 채널마다 PEQ · FIR · 게인 · 딜레이 값을 표로(+ FIR wav). RC 만 적용한 결과에서 씁니다.
- EqAPO 내보내기: Equalizer APO 설정째로 냅니다. config 폴더에 복사하고 입출력 번호만 맞추면 됩니다. RC · BA 까지 지원합니다.
- CamillaDSP 는 RC · BA · MIMO 모두 지원합니다.

MIMO

- 새 프로젝트는 서포트 필터를 FIR 로 시작합니다([FIR 사용] 켜짐).

## SECS 2 Beta 1.2.0 — 2026-10-12

MIMO

- 서포트 필터를 FIR 로 쓸 수 있습니다([FIR 사용], 서포트당 8,000탭). IIR 보다 계산이 빠르고 FIR 탭을 많이 씁니다.
- IIR 서포트 PEQ 가 지나치게 큰 게인을 덜 쓰도록 바꿨습니다.

BA

- '서브 정렬' 을 BA (Bass Alignment) 로 부릅니다.
- 서브 필터가 대역을 막거나 서브 게인이 지나치게 크면 빨간 경고가 나옵니다.
- 인프라 서브를 묶음 서브로 골랐다 되돌리면 LP 가 남던 문제를 고쳤습니다.
- [서브만 계산] 중에도 예상 시간이 보입니다.

그 밖

- CamillaDSP 프로필의 총 FIR 탭 예산을 2배로 늘렸습니다.
- '타깃' 을 '타겟' 으로 바꾸고, 도움말 그림을 새 화면으로 바꿨습니다.
- 튜토리얼 완료 창의 버튼을 [튜토리얼 종료] 로 바꿨습니다.

## SECS 2 Beta 1.1.0 — 2026-10-11

mdat 불러오기

- 여러 위치를 담은 mdat 를 불러올 때 '같은 역할이 두 번 배정됐습니다' 로 막히던 문제를 고쳤습니다.
- 배정 창에서 측정마다 위치를 고를 수 있습니다.
- 측정 화면의 [파일 관리] 에서 위치마다 mdat 파일을 따로 불러오거나 그 위치만 비울 수 있습니다.
- 다시 불러오면 새 파일에 든 위치 · 채널만 바뀌고, 나머지 측정은 그대로 남습니다.
- 불러온 파일 이름이 위치 목록 아래에 보입니다.
- `SW 2` 처럼 띄어 쓴 번호는 위치로 읽습니다(SW1 의 위치 2). 서브가 여럿이면 `SW2` 처럼 붙여 씁니다. `Subwoofer` · `서브` · `서브우퍼` 도 SW1 로 알아봅니다.
- 이름에 위치가 없는 파일은 다음 위치로 들어갑니다.
- 배정 창의 채널 이름을 다른 화면과 같게 맞췄습니다.

측정 화면

- [그래프 숨기기] 로 그래프를 끄면 측정 위치 배치도가 크게 보입니다.
- 배치도의 번호 · 글자를 키웠습니다.
