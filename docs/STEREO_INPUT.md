# 2채널 음원과 MIMO 서포트

이슈 #106의 조사 기록입니다. Dirac Live ART를 데논 리시버에서 쓸 때 사운드 모드를 '스테레오'로 두면 보정이 깨지는 현상이 알려져 있습니다([디시 461211](https://gall.dcinside.com/mgallery/board/view/?id=speakers&no=461211), [디시 582472](https://gall.dcinside.com/mgallery/board/view/?id=speakers&no=582472)). SECS 2R에도 같은 일이 생기는지 확인했습니다.

## ART에서 생기는 일

- 데논의 '스테레오' 모드는 프론트 L·R과 서브우퍼에만 신호를 보내고, 센터와 서라운드를 끕니다. 업믹서 모드(돌비 서라운드, 오로 3D, 뉴럴 X)에서는 모든 채널이 켜집니다.
- ART는 프론트 L의 저음을 서브, 프론트 R, 센터, 서라운드 같은 서포트 스피커로 함께 내보내 늦은 울림을 줄입니다. 그런데 스테레오 모드에서는 리시버가 서포트 채널을 끄기 때문에, 서포트 몫이 빠져 80–150 Hz가 무너집니다.
- 사용자들은 오로 3D를 고르고 강도를 0으로 두어 업믹스 없이 모든 채널을 켜는 식으로 피했습니다.

## SECS 2R에서는

SECS 2R이 내보낸 설정에서는 MIMO 서포트 신호를 필터 안에서 입력 채널로부터 직접 나눠 만듭니다. Equalizer APO는 `Copy:`, CamillaDSP는 `mimo_fork` 믹서, 컨볼루션 IR은 입력→서포트 출력 쌍의 WAV가 이 일을 합니다. 서포트 스피커의 입력 채널(센터, 서라운드)에 원래 신호가 있는지는 상관이 없습니다. 그래서 2채널 음원도 L과 R의 서포트 스피커와, BA로 저음을 받는 서브에 그대로 닿습니다.

`secs-filters::stereo_source_reaches_every_support_and_sub_of_its_inputs_i106`이 이 성질을 지킵니다. 이 테스트는 서브와 LFE가 있는 돌비 배치와 MIMO 배치에서 L과 R에만 신호를 넣고, L과 R의 모든 MIMO 서포트 출력과 BA 서브 출력이 소리를 내는지 확인합니다. 입력마다 모든 출력의 응답이 설계와 같은지는 Equalizer APO(공식, XT)와 CamillaDSP 재생 검사가 확인합니다([`EQUALIZER_APO_INTEROP.md`](EQUALIZER_APO_INTEROP.md), [`CAMILLADSP_INTEROP.md`](CAMILLADSP_INTEROP.md)).

## 그래도 깨질 수 있는 경우

필터 앞에서 채널이 사라지면 SECS 2R도 같은 증상을 냅니다. 원인은 모두 재생 환경이고, 필터는 고칠 것이 없습니다.

- **Windows의 스피커 구성이 2채널일 때.** Equalizer APO는 Windows가 넘기는 채널 수만큼만 처리합니다. 장치를 스테레오로 두면 센터, 서라운드, 서브 출력이 없어 서포트와 BA가 함께 빠집니다. Equalizer APO 안내 파일이 말하듯, 장치의 스피커 구성을 설정의 출력 번호가 다 들어가는 채널 수로 맞춰야 합니다.
- **CamillaDSP의 재생 장치 채널이 모자랄 때.** 내보낸 설정은 출력 수만큼의 채널을 요구하므로, 장치가 그보다 적으면 CamillaDSP가 시작하지 않습니다. 조용히 빠지지는 않습니다.
- **컨볼버가 2채널로만 출력할 때.** 컨볼루션 IR의 서포트 쌍(`L_to_C.wav` 등)을 걸 출력이 없으면 서포트 몫이 빠집니다. `routing.json`의 모든 쌍을 걸 수 있는 다채널 컨볼버를 써야 합니다.

## 남은 것

- SECS 1에서 '프론트가 두 번 들린다'는 제보가 있었지만(디시 582459), 재현 조건을 아직 받지 못했습니다. 측정 장치와 재생 환경을 받는 대로 다시 봅니다.
- 리시버(데논, 마란츠)에 직접 필터를 넣는 기능은 SECS 2R에 없으므로, 리시버 사운드 모드에 따른 차이는 이 저장소에서 확인하지 않았습니다.
